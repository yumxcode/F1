# 踝关节阻尼方法复核与可判定方案

> 复核对象：`plans/踝关节阻尼谐振分析方法论.md`、`scripts/ankle_damping_analysis.py`、`reports/踝关节阻尼分析报告.md`  
> 结论：行走日志 FRF 不适合作为 real 踝关节阻尼比/固有频率的主判据；应改用专项 step/sine 模态辨识。

## 1. 现有报告 real 大量“无法判断”的根因

1. `ankle_damping_analysis.py` 的主判据是摆动相 `pos_des -> joint_pos` FRF，并要求 `coh_sw >= 0.40` 才输出 `G_fn_sw / zeta_frf_swing`。
2. 真机行走数据是闭环、非平稳、短摆动段、强接触扰动数据；每段摆动约 0.2–0.4s，频率分辨率和相干度天然差。
3. 更关键的是，控制器对踝关节走的是 parallel torque path：`src/module/control_module/src/rl_controller.cc` 中 `is_parallel=1` 时实际下发 `joint_cmd.effort = tau_des_lpf`，而不是位置命令。`pos_des_raw` 只是内部虚拟目标，用来计算 `tau_des = Kp(pos_des-q)-Kd*qdot`。
4. 因此，用 `pos_des_raw -> joint_pos` 做单输入 FRF，会把“策略目标、PD 误差、力矩低通、机械传动、接触扰动”混在一起。低相干不是偶然，而是方法与数据条件不匹配。

## 2. 对已有方法的保留/降级

行走日志仍然有价值，但只能回答“是否出现低阻尼/自激风险”，不能严格估计 `zeta/fn`。

保留为风险指标：
- `range_gain_phase > 1`、`joint_vel > target_vel`：局部自激/能量注入证据；
- `A_peak`、touchdown 后残差：接触冲击放大证据；
- `delay_ms`：相位裕度风险；
- `zeta_theory = Kd/(2*sqrt(Kp*J_eff))`、`fn_theory = sqrt(Kp/J_eff)/(2*pi)`：参数先验，不是实测结论。

降级或废弃为定量阻尼判据：
- 行走 `pos_des -> joint_pos` FRF：real 低相干时不得输出定量 `zeta/fn`；
- touchdown log-decrement：目标仍在移动，通常不是自由衰减；
- 残差 PSD 主峰：多为步态/接触激励频率，不一定是机械固有频率。

## 3. 可判定方法：专项 step/sine 模态辨识

使用已有 `src/module/ankle_identifier_module` 采集专项数据，而不是从行走日志硬估计。

推荐两级流程：

1. Step / pulse test：四个踝关节轴分别小幅阶跃，脚悬空或轻载，其他关节高刚度 hold。用带延迟二阶闭环模型拟合完整输入输出：

   `q(t)-q0 = H(s) * (target(t-delay)-target0) + bias`

   `H(s) = gain * wn^2 / (s^2 + 2*zeta*wn*s + wn^2)`

   拟合参数直接给出 `fn = wn/(2*pi)` 和 `zeta`。这适用于有/无超调的响应，比只看 overshoot 更通用。

2. Multi-sine / frequency sweep：若 step 无超调且 `zeta` 与 `fn` 耦合不稳定，运行 `mode: sine`，频点覆盖 `0.5, 1, 1.5, 2, 3, 4, 5, 6, 8, 10 Hz`。对幅相 FRF 拟合同一个二阶模型，可区分“真正过阻尼”与“响应幅值低/摩擦/限幅”。

质量门槛：
- step/sine 激励幅值 ≥ 0.003 rad；
- 每个轴至少 3 次重复；
- 拟合 `R² >= 0.80`；
- `gain/fn/zeta` 不贴优化边界；
- real 与 sim 使用相同测试姿态、Kp/Kd、幅值、采样率。

## 4. 已新增分析脚本

新增：

`sim2real/walk_data_analysis/scripts/ankle_modal_identification.py`

功能：
- 读取 `ankle_identifier_module` CSV：`time_sec, phase, target_primary, actual_primary...`
- 对实际 target 轨迹做带延迟二阶闭环拟合，支持 step、pulse、sine；
- 输出 `zeta`、`fn_hz`、`delay_ms`、`gain`、`R²`；
- 写入：
  - `sim2real/walk_data_analysis/table/ankle_modal_id/ankle_modal_id_results.csv`
  - `sim2real/walk_data_analysis/reports/踝关节模态辨识报告.md`

运行：

```bash
conda run -n x1 python sim2real/walk_data_analysis/scripts/ankle_modal_identification.py
```
