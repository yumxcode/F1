# 踝关节欠阻尼/谐振分析 — 指标与判断标准 (v5.2)

> 详细理论推导见 [谐振问题方案.html](谐振问题方案.html)  
> 最后更新: 2026-05-14
> **v5.2 改动**：coh 门限 0.40→0.30；时域指标从"兜底"升级为 Real 端主力判定工具；决策树重构；新增 sine-sweep 推荐

---

## 一、核心警告

**⚠️ 全步态 G_fn < 0.5 ≠ 过阻尼**：支撑相 J_eff 增大 4–8 倍 → fn_eff 下移至 1–1.5 Hz → 在 fn_th 处 FRF 已跌入滚降区 → G_fn 虚低。必须用**摆动相分离 FRF（G_fn_sw）**确认真实阻尼。

**⚠️ 控制器形式前提**：本文档所有公式假设 PD 控制器为**仅关节速度微分**（无零点）形式，即 τ = Kp·e − Kd·q̇。若为完整误差微分形式（τ = Kp·e + Kd·ė），G_fn 解读方法不同，需另行分析。

## 二、核心指标

### 2.1 一级指标（直接决定阻尼结论）

| 指标 | 符号 | 计算方法 | 判断阈值 |
|------|------|----------|----------|
| **摆动相 FRF 幅值** | $G_{fn,sw}$ | 仅摆动相时段 FRF，取 fn_th 处幅值 | > 1.5 欠阻尼；0.5–1.5 临界；< 0.5 过阻尼 |
| **摆动相阻尼比** | $\zeta_\text{FRF,sw}$ | $\zeta = 1/(2\cdot G_{fn,sw})$（需 coh_sw ≥ 0.30） | < 0.5 欠阻尼；0.5–1.0 临界；> 1.0 过阻尼 |
| **摆动相相干函数** | $\text{coh}_{sw}$ | fn_th 处 FRF 估计信噪比 | ≥ 0.30 结论可信；< 0.30 弃用，以时域指标替代 |
| **摆动相跟踪误差** | $e_\text{RMS,sw}$ | contact=0 时段 RMS(pos − des) | sim/real gap 定位；越小越好 |
| **支撑相跟踪误差** | $e_\text{RMS,st}$ | contact=1 时段 RMS(pos − des) | 反映接地冲击稳定性 |
| **时域幅值增益** | $G_\text{amp}$ | 每步 max(|jnt|)/max(|des|) | **Real 端主力判定**：> 1.5 + 自激 > 0 = 欠阻尼 |
| **自激点计数** | — | joint_vrms > target_vrms 的周期数 | > 0 存在能量注入 |

### 2.2 二级指标（辅助判定）

| 指标 | 符号 | 计算方法 | 用途 |
|------|------|----------|------|
| 自然频率（理论） | $f_n^\text{th}$ | $\sqrt{K_p/J_\text{eff,sw}}/(2\pi)$ | 计算 fn_th，J_eff,sw ≈ 0.0965 kg·m² |
| 自然频率（FRF相位） | $f_n^\text{FRF}$ | 延迟补偿后 ∠H_sw = −90° 处（无零点系统有效） | 与 fn_th 对比，验证 J_eff 估计 |
| 全步态 FRF 幅值 | $G_{fn}$ | 全信号 FRF 取 fn_th 处幅值 | 参考量，须配合 G_fn_sw 解读 |
| 接地过冲幅度 | $A_\text{peak}$ | 接地后 150ms 峰值/400ms 后稳态均值 | 冲击响应，独立于 G_amp |
| 控制延迟 | $\tau_d$ (ms) | 摆动相 xcorr 中位数 | fn 处相位损耗 = 360°·fn·τd/1000 |
| 左右不对称指数 | $\Delta_{LR}$ | e_RMS_left / e_RMS_right | 机械/控制不对称 |

### 2.3 已废弃指标

| 指标 | 废弃原因 |
|------|----------|
| ζ_hat（对数递减法） | 步行数据强迫振动，自由衰减前提不成立 |
| ζ_BW（半功率带宽法） | 仅适用欠阻尼系统（有谐振峰） |
| 残差 PSD 主峰作为 fn | 是误差灵敏度峰，受步态输入谱主导 |

## 三、判断标准

### 3.1 阻尼诊断决策树（v5.2 修正版）

**核心原则**：Real 端行走数据 coh_sw 普遍 < 0.30（非线性 + 激励不足），
**时域指标是 Real 端的主力判定工具**，FRF 仅在 coh 达标时补充确认。

```
┌─ 有阶跃实验（悬空）？
│     YES → ζ_step < 0.5 欠阻尼 / ≥ 0.5 过阻尼        ← 最可信 ★★★★★
│     NO  → 继续
│
├─ 时域指标（不依赖 coh，始终可用）                       ← Real 端主力 ★★★★
│     amp_gain_swing > 1.5 + n_self_excite > 0
│       → 🔴 时域确认欠阻尼行为（足够工程决策）
│     amp_gain_swing > 1.0 + A_peak > 2.0
│       → 🟠 冲击放大，疑似欠阻尼
│     amp_gain_swing < 1.0 + n_self_excite = 0
│       → 🟢 未见欠阻尼行为
│
└─ 摆动相 FRF（需 coh_sw ≥ 0.30 且 n_sw ≥ 5）
      YES → G_fn_sw 判定（见 3.2 表）                   ← 补充确认 ★★★
      NO  → 时域结论已足够，FRF 暂不可用
```

> **为什么 Real 端时域优先于 FRF？**
> Real 行走数据中传动间隙、摩擦、接触切换破坏了 FRF 的线性时不变假设，
> coh_sw 普遍 < 0.30。但 amp_gain 和自激点不依赖线性假设，
> 且所有 Real 端时域检出的失稳事件（25/0.4 R roll、40/0.8 R roll）
> 均与阶跃实验（35/0.5）方向一致。时域指标在 Real 端是**可信且充分**的判定工具。

### 3.2 G_fn_sw 阻尼判断表

| coh_sw | G_fn_sw | ζ_frf_sw | 阻尼结论 | 建议动作 |
|--------|---------|----------|---------|----------|
| ≥ 0.30 | > 1.5 | < 0.33 | **欠阻尼** | 增大 Kd |
| ≥ 0.30 | 1.0–1.5 | 0.33–0.5 | 弱欠阻尼 | 适度增大 Kd |
| ≥ 0.30 | 0.5–1.0 | 0.5–1.0 | 临界/弱过阻尼 | 可维持或小幅调整 |
| ≥ 0.30 | < 0.5 | > 1.0 | **过阻尼** | 降低 Kd |
| < 0.30 | 任意 | — | **FRF 不可信** | 用时域指标判定；做阶跃实验或 sine-sweep |

> **coh 门限从 0.40 降至 0.30 的理由**：40/0.8 R roll 的 coh_sw=0.38、G_fn_sw=2.19 明确有信号，
> 0.40 门限过于严格导致假阴性。0.30 是工程上 FRF 幅值可信的合理下界。

### 3.3 各方法的有效范围与推荐优先级

| 方法 | 适用场景 | 不适用场景 | 推荐优先级 |
|------|---------|-----------|----------|
| 阶跃实验（悬空） | 所有 Kp/Kd，悬空 | 触地（需单独做） | ★★★★★ 最高 |
| 时域指标（amp_gain + 自激） | 所有行走数据 | —（无需假设） | ★★★★ Real 端主力 |
| 摆动相 FRF（G_fn_sw） | coh_sw ≥ 0.30, n_sw ≥ 5 | Real 端大多不满足 | ★★★ 补充确认 |
| 全步态 FRF（G_fn） | 仅作参考 | 受支撑相 J_eff 污染 | ★★ 参考 |
| Sine-sweep 实验 | 需要宽带激励的场景 | — | ★★★★★ 推荐补充 |

### 3.4 诊断矩阵（v5.2）

| 现象 | 指标组合 | 诊断 |
|------|----------|------|
| 时域确认欠阻尼 | amp_gain_swing > 1.5 + n_self_excite > 0 | **足够工程决策**，增大 Kd |
| FRF 确认欠阻尼 | G_fn_sw > 1.5 + coh_sw ≥ 0.30 | 与时域交叉验证 |
| 阶跃确认欠阻尼 | ζ_step < 0.5 + 悬空超调 | **最可信**，直接调参 |
| 摆动态过阻尼 | G_fn_sw < 0.5 + coh_sw ≥ 0.30 + amp_gain < 1.0 | 过保守，可降 Kd |
| 支撑态惯量问题 | G_fn < 0.5 且 G_fn_sw > 1.0 | J_eff_stance 压低 fn_eff，非阻尼问题 |
| 接触态阻尼崩溃 | ζ_step_touchdown ≈ 0 | 接触约束消除阻尼，需 stance 分离 Kd |
| sim2real gap | Real G_fn_sw / amp_gain >> Sim | Real 欠阻尼或 Sim 过阻尼，分侧调参 |
| **FFT 自激确认** | **pos @fn 振幅 ≫ des @fn 振幅**（如 pos=0.014, des=0.001 rad） | **最直接的自激证据**——关节在目标几乎不动的频率上产生显著运动，不依赖 coh/线性/J_eff |

## 四、Kp/Kd 调整指南

**目标**：ζ_frf_sw ∈ [0.3, 0.7]（轻度欠阻尼，跟踪快且不振荡）

**约束**：$\zeta \propto K_d/\sqrt{K_p}$，增大 Kp 时必须按比例增大 Kd

**步骤**：
1. 由所需 fn 反推：$K_p = J_\text{eff,sw} \cdot (2\pi f_n)^2$
2. 由目标 ζ 反推：$K_d = 2\zeta\sqrt{K_p \cdot J_\text{eff,sw}}$
3. 验证：G_fn_sw ∈ [0.7, 1.7]，A_peak < 2.0

**参考值**（J_eff,sw = 0.0965 kg·m²）：

| Kp | Kd 当前 | ζ_th | Kd 建议 (ζ=0.4) | Kd 建议 (ζ=0.7) |
|----|---------|------|----------------|----------------|
| 25 | 0.4 | 0.129 | 0.99 | 1.73 |
| 35 | 0.5 | 0.136 | 1.17 | 2.05 |
| 40 | 0.8 | 0.204 | 1.25 | 2.19 |

## 五、自然频率获取方法（诚实版）

### 5.0 我们实际上没有从行走数据中独立获取 fn 的有效方法

这是当前方法论的一个**已知局限**。所有 G_fn_sw 的计算，都是**假设 $f_n = f_n^\text{th}$**，
在 $f_n^\text{th}$ 处读取 FRF 幅值，而非从数据中测量 fn 后再读取 G_fn。

以下逐条说明三条路径的现状、局限、以及务实的应对方式。

---

### 5.1 方法 A：理论值 $f_n^\text{th}$（当前实际在用）

$$\boxed{f_n^\text{th} = \frac{1}{2\pi}\sqrt{\frac{K_p}{J_\text{eff}}},\quad J_\text{eff} \approx 0.0965\ \text{kg·m}^2}$$

**优点**：始终可算，不依赖信号质量。

**问题**：$J_\text{eff}$ 到底是不是 0.0965？

- 摆动相空载 vs 触地约束，$J_\text{eff}$ 差 4–8 倍
- 小幅值（死区未克服）vs 大幅值（传动间隙打开），等效惯量也不同
- 左腿 vs 右腿，机械不对称
- 如果用错了 $J_\text{eff}$ → $f_n^\text{th}$ 偏了 → 在错误频率处读 G_fn → $\zeta$ 也跟着偏

**务实判断**：$J_\text{eff}$ 偏差 2× → $f_n^\text{th}$ 偏差 $\sqrt{2}\times \approx 1.4\times$。
对于 Kp=35，$f_n^\text{th}$ 从 3.0 Hz 偏到 4.2 Hz，仍在摆动相 FRF 的合理搜索范围内。
且 G_fn 的方向性（>1 还是 <1）对 ±0.5 Hz 的频率偏差不敏感——
只要 $J_\text{eff}$ 偏差不超过 2×，阻尼方向判定不受影响。

---

### 5.2 方法 B：FRF 相位法 $f_n^\text{FRF}$

**原理**：$\angle H_{CL}(j\omega_n) = -90°$（对任意 $\zeta$ 严格成立，推导见附录 A8）。
延迟补偿后，在 $[f_n^\text{th} \pm 2\text{Hz}]$ 范围内找相位最接近 -90° 的频点。

**步骤**：
1. 计算摆动相 FRF：$H_{sw}(f) = \text{csd}(des, jnt)/S_{xx}(des)$（仅 contact=0 片段）
2. xcorr 估计延迟 $\tau_d$，相位补偿 $H_{comp} = H \cdot e^{+j2\pi f \tau_d}$
3. 找 $\angle H_{comp}(f)$ 最接近 -90° 的频点

**适用条件**：coh_sw ≥ 0.30（相位估计需要足够的 SNR）

**实际情况**：

| 数据源 | coh_sw | fn_frf 可用性 |
|--------|--------|-------------|
| Sim | 0.3–0.9 | ✅ 高 coh，fn_frf 可用，与 fn_th 偏差通常在 ±1 Hz 内 |
| Real | 0.02–0.4 | ❌ 多数 coh < 0.30，相位曲线噪声大，-90° 过零点不唯一或不存在 |

---

### 5.3 方法 C：阶跃实验振铃周期法 $f_n^\text{step}$

**原理**：阶跃响应释放后的振铃周期 $T_d$ → $f_d = 1/T_d$ → $f_n = f_d / \sqrt{1-\zeta^2}$

**实测数据**（来自 34 号报告，`right_ankle_roll`, Kp=35/Kd=0.5）：

| 工况 | 幅值 (rad) | fn (Hz) | 备注 |
|------|-----------|---------|------|
| 悬空 | 0.05 | 3.5 / 18.9 / 17.1（三次） | 同幅值复测差异 5× |
| 悬空 | 0.10 | 11.0 / 27.9 / 14.8（三次） | 大幅值 fn 更高 |
| 悬空 | 0.15 | 27.5 / 16.3 / 15.3（三次） | 峰值数从 108→5，模态不同 |
| 触地 | 0.05–0.25 | 2.6–26.8 | 极度分散，模态混杂 |

**结论**：阶跃实验的 fn 随幅值、复测状态、接触条件剧烈变化（3.5→27.9 Hz），
**不能把单次 $f_n$ 当作系统的唯一固有频率**。真实系统是非线性 + 多模态的，
fn 本身就是状态依赖的。

---

### 5.4 方法 D：残差 PSD 主峰（已废弃）

残差 `e = pos − des` 的 Welch PSD 主峰是**跟踪误差灵敏度峰**，不是谐振频率。
任何系统（包括过阻尼）在带宽附近都有一个误差峰。已在 v3 废弃。

---

### 5.5 务实做法总结

| 场景 | 推荐方法 | 精度 | 备注 |
|------|---------|------|------|
| **日常分析** | 方法 A：$f_n^\text{th}$ | ±30%（取决于 $J_\text{eff}$ 精度） | 当前实际在用；阻尼方向判定不受影响 |
| **Sim 端验证** | 方法 B：$f_n^\text{FRF}$（相位法） | ±0.5 Hz | coh 高，可用 |
| **Real 端精确** | 方法 C：悬空阶跃实验，取中位数 | ±2 Hz（多次平均） | 仅给出系统固有分量，非行走真实 $f_n$ |
| **Real 行走 fn** | **无法精确获取** | — | $f_n$ 随 $J_\text{eff}$ 时变，本身不是定值 |

**关键认知**：$f_n$ 在行走中本身是时变的，追求单一精确值在物理上可能没有意义。
当前方案的务实策略——用 $f_n^\text{th}$ 作为评估点，用 $G_{fn,sw}$ 的方向性
（>1 欠阻尼 / <1 过阻尼）做阻尼判断——在工程上是自洽且有效的。

未来改进方向：用 sine-sweep（2–10 Hz 扫频）直接测量闭环频响 $|H(f)|$，
从幅值曲线的峰值频率直接读取 $f_n$，不依赖 $J_\text{eff}$ 假设。
这是最可靠的方法，但需要专项实验。

## 六、分析工作流（v5.2）

> 注："判断标准"见[第三节](#三判断标准)，"自然频率获取"见[第五节](#五自然频率获取方法诚实版)，"Kp/Kd 调整"见[第四节](#四kpkd-调整指南)。

```
1. 接地/离地事件检测（去抖，MIN_TD_GAP=0.3s）
2. 分相位 eRMS → e_RMS_swing, e_RMS_stance
3. 摆动相分离 FRF（核心）
   - 仅 [liftoff+0.05s, touchdown-0.05s] 时段做分段累积谱
   - G_fn_sw = |H_sw(fn_th)| → ζ_frf_sw = 1/(2·G_fn_sw)
   - 延迟补偿后 ∠H_sw=-90° 处 → fn_frf_sw
4. 全步态 FRF（参考） → G_fn, ζ_frf（配合 G_fn_sw 解读）
5. 时域指标 → A_peak, delay_ms, G_amp, ΔLR
6. 综合判定（见第三节决策树）
```

## 七、方法局限性

- **摆动相时长短**：每步约 0.35–0.45s，频率分辨率约 2–3 Hz，fn 附近谱估计精度有限
- **低相干时不可信**：coh_sw < 0.30 时 G_fn_sw 无效，改用时域指标判定，做阶跃实验或 sine-sweep 补充
- **J_eff 时变**：支撑/摆动相 J_eff 差异 4–8 倍，分相位控制（摆/支不同参数）是根本解法
- **控制器形式未确认**：所有结论依赖无零点 G_CL 假设，需阶跃实验交叉验证
