## 一、目的

将 forward-x failure 的分析结论固化为可复现的测试指标方案。核心问题：

```
forward-x 失败主线 =
  real 踝关节欠阻尼（ζ_step=0.07–0.25, 触地 ζ≈0）
  + touchdown 冲击（gain 5–18×, 自激 1–7 点）
  + target 高频换向（22–37 Hz, 超带宽 3–5×）
  + 传动弹性储能
  → ankle roll / pitch 过冲、自激、锁死、步间累积
```

## 四、A 组：时域指标详细定义（M1–M9）

### M1. `lag_ms` + `corr`

```
lag_ms = argmax_lag corr(diff(des), diff(joint))
corr   = 对齐后相关系数
```

| corr | 含义 |
|------|------|
| ≥0.4 | 延迟可信，线性传递存在 |
| 0.1–0.4 | 弱相关，延迟仅参考 |
| <0.1 | 解耦——冲击、锁死、自激 |

> `corr < 0.1` → 标记 `decoupled_window`，不得用 lag_ms 解释延迟。

### M2. `aligned_track_err`

```
aligned_track_err = RMS(joint(t+lag) - des(t))
```

| 等级 | 条件 |
|------|------|
| watch | ≥0.15 rad |
| risk | ≥0.20 rad |
| fail | ≥0.25 rad 且 corr<0.2 |

### M3. `amplitude_gain`

```
amplitude_gain = joint_range / target_range  (target_range ≥ 0.01 rad)
```

| 范围 | 含义 |
|------|------|
| <0.5 | 欠跟踪（sim roll 常见） |
| 0.5–1.2 | 正常 |
| 1.2–2.0 | 过跟踪 / 低阻尼放大 |
| >2.0 | 冲击过冲 / 自激风险 |

> gain>1 的窗口须检查 M5/M11 确认机制。

### M4. `target_direction_change_rate_hz`

```
target_oscillation_hz = 每秒速度符号反转次数 / 2
f_stable_max ≈ 1/(4×0.076s) ≈ 3.28 Hz（76ms 延迟下的稳定带宽）
```

| 等级 | 条件 |
|------|------|
| pass | ≤3.3 Hz |
| watch | 3.3–6 Hz |
| risk | 6–10 Hz |
| fail | >10 Hz |

### M5. `vel_ratio`（自激点）

```
vel_ratio = RMS(d joint/dt) / RMS(d des/dt)
```

| 范围 | 含义 |
|------|------|
| <0.5 | 正常低通衰减 |
| 0.5–1.0 | 响应偏强，需结合 gain 判断 |
| >1.0 | **自激候选**——关节速度超目标，存在额外能量注入 |

> 同一 case 出现 ≥2 个自激候选 → `unstable_for_forward_x`。

### M6. `sole_roll_at_touchdown`

优先 FK 计算，不用 `ank_roll` 替代。

| abs(sole_roll) | 等级 |
|---------------|------|
| <5° | pass |
| 5–8° | watch |
| 8–15° | risk |
| >15° | fail |
| >25° | critical |

> `abs(sole_roll) - abs(ank_roll) > 8°` → 标记 `joint_angle_blind_spot`。

### M7. `touchdown_ankle_pitch_mean/std`

| 指标 | watch | fail |
|------|-------|------|
| pitch_mean | >-0.18 rad | >-0.10 rad |
| pitch_std | >0.08 rad | >0.12 rad |
| knee_std | >0.08 rad | >0.15 rad |

### M8. `joint_lock_flag`

```
joint_range < 0.02 AND target_range > 0.10 AND aligned_track_err > 0.25
```

任一 ankle 锁死 → `hardware_protection_failure`。

### M9. `step_accumulation_score`

跟踪 `sole_roll`, `amplitude_gain`, `vel_ratio`, `aligned_track_err` 的跨步趋势。

| 等级 | 条件 |
|------|------|
| watch | 任一指标连续 2 步上升 |
| risk | 连续 3 步上升 |
| fail | `abs(sole_roll)>15°` 或 `vel_ratio>1` 后下一步未恢复 |

## 五、B 组：频域指标详细定义（M10–M12）

### M10. `pos-vs-des @fn`（FFT 振幅对比）★ 最直接的自激证据

**原理**：读取 $f_n^\text{th} \approx 3.0$ Hz 处，pos 和 des 各自的 FFT 振幅。

```
若 pos @fn ≫ des @fn（如 pos=0.014 rad, des=0.001 rad）：
  → 关节在目标几乎不动的频率上产生了显著运动
  → 这个频率分量只能来自系统自身（自激振荡 / 欠阻尼谐振）
  → 不需要 coh，不需要 FRF，不需要 J_eff 精度
```

**实测**（right_ankle_roll, 25/0.4, @3.0 Hz）：

| 数据源 | pos @3Hz | des @3Hz | 解读 |
|--------|---------|----------|------|
| **real** | **0.0144 rad** | 0.0010 rad | 🔴 自激振荡 |
| sim | 0.0003 rad | 0.0012 rad | 🟢 正常 |

**输出**：每个 case × side × axis × phase 的 `pos_amp_at_fn`、`des_amp_at_fn`、`pos_des_ratio_at_fn`。

**判据**：`pos_amp_at_fn > 0.005 rad` 且 `des_amp_at_fn < 0.002 rad` → `self_oscillation_confirmed`。

---

### M11. 频率-增益交叉统计

**回答**：amplitude_gain > 1 的事件集中在哪个频率段？

**方法**：逐窗口联合 `amplitude_gain` 和 `target_dominant_freq_hz` / `f_modal_candidate_hz`，按 Kp/Kd × phase 分组输出：

```
- gain>1 事件在各频率 bin (2-4/4-6/6-10/10-20/20+ Hz) 的计数和 avg_gain
- freq_gap ≤ 1.0/1.5/2.0 Hz 时的 gain>1 占比和 avg_gain
```

| 频率分布特征 | 指向 |
|------------|------|
| gain>1 集中于 2–4 Hz（≈ fn_th） | 谐振放大 |
| gain>1 集中于 6–10 Hz | 高频激励 + 低阻尼 |
| freq_gap ≤ 1 Hz 时 avg_gain 明显升高 | 频率接近 = 谐振条件 |

**判据**：`freq_gap ≤ 1.5 Hz` 且 `amplitude_gain > 2` → `resonance_likely`。

**实测关键数据**（v5.2）：

| Kp/Kd | phase | gain>1 | avg_gain | gap≤1Hz avg | 频率分布（gain>1 事件数） |
|-------|-------|--------|----------|------------|--------------------------|
| 25/0.4 | swing | 8/24 33% | 3.95 | 4.34 | 2-4Hz:1, 4-6Hz:1, **6-10Hz:6** |
| 25/0.4 | td | 8/24 33% | 2.65 | 2.46 | **6-10Hz:7**, 10-20Hz:1 |
| 30/0.4 | td | 8/24 33% | 3.12 | 4.40 | 6-10Hz:3, 10-20Hz:3, 20+:2 |
| 35/0.5 | swing | 5/24 21% | 2.40 | — | **2-4Hz:3**, 4-6Hz:2 |
| 40/0.8 | td | 8/24 33% | **5.19** | **5.84** | **6-10Hz:5**, 10-20Hz:2, 20+:1 |

### M12. 整体 FFT 频谱分析

**回答**：所有数据的频率成分是什么（无条件频谱）？

**方法**：per-file × per-joint × per-phase 的 Hanning FFT：
- Top 3 peaks in [0.5, 20] Hz
- 分带能量比：2–4 / 4–8 / 8–15 / 15–20 Hz
- 振荡幅度：pos_osc_rad = std(pos), err_osc_rad = std(err)

**与 M10 的关系**：M10 是在 M12 的 FFT 数据上做的 fn 处 pos-vs-des 专项对比。

**与 M11 的关系**：M12 是无条件频谱（背景），M11 是条件分布（gain>1 事件的频率特征），互补。

**判据**：
- `pos 主峰 ≈ fn_th`（而非步态基频）→ 振荡分量主导关节运动
- `err_osc_rad: real ≫ sim` → real 有额外振荡能量
- `pos_energy_4-8Hz` 最高者 → 与 gain 最高的 Kp/Kd 一致

## 七、综合判定规则

### 7.1 Case 级判定

| 状态 | 条件 |
|------|------|
| `pass` | 无 lock；自激=0；sole_roll≤8°；主要 tracking err 未进入 fail |
| `watch` | 轻度 sole_roll 或 target 高频，但无自激、无锁死 |
| `risk` | 出现 vel_ratio>1 或 gain>2 或 sole_roll>15° 任一项 |
| `fail` | 出现 lock 或 sole_roll>25° 或连续步间恶化且未恢复 |

### 7.2 预期归类

| Case | 状态 | 依据 |
|------|------|------|
| real 25/0.4 | `risk` | swing 33% gain>1, avg_gain=3.95；R roll 自激 4 点；M10 确认自激振荡 |
| real 30/0.4 | `risk` | touchdown gain 分散；R roll 自激 1 点 |
| real 35/0.5 | `fail` | step4 起右踝锁死；阶跃确认触地 ζ≈0 |
| real 40/0.8 | `fail` | R side gain 5–18×, 自激 1–7 点；M10/M11/M12 三方交叉验证 |
| sim 全部 | `model_gap` | 无自激、无锁死；过阻尼（ζ_frf>0.7）；swing roll 欠响应 |

### 7.3 欠阻尼证据链（real 端）

按假设依赖从低到高排列：

| 优先级 | 方法 | 依赖假设 | 状态 |
