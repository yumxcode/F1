## 诊断工作流执行

按方法论第七节决策树，对每个已知 Kp/Kd 的 Case 逐步执行判定。

### 工作流步骤回顾

```
Step 1: 读取 ζ_theory / ζ_hat / ζ_BW → 判定欠阻尼严重度
Step 2: 读取 fn_swing / fn_stance → 判定谐振源
Step 3: 读取 Mr / PM / τ_decay → 量化谐振风险
Step 4: 读取 amplitude_gain / 自激点 → 判定自激
Step 5: 读取 delay / phase_loss → 判定延迟影响
Step 6: 读取 A_peak / target_dir_chg → 判定冲击/激励源
Step 7: 交叉对比 real vs sim → 定位 sim2real gap
Step 8: 输出诊断结论 + 建议 Kp/Kd 调整方向
```

#### 1.1 理论预判

#### 1.3 诊断结论 (25/0.4)

```
┌─────────────────────────────────────────────────────────────┐

│                                                             │
```

## 二、真机 vs 仿真系统性对比 (25/0.4 + 35/0.5)

这是仅有的两组同时有 real 和 sim 数据的参数。

### 2.1 核心指标差异

| 指标 | 25/0.4 real→sim | 35/0.5 real→sim | 方向 |
|------|----------------|----------------|------|
| e_rms (pitch) | 0.322 → 0.268 (+20%) | 0.464 → 0.264 (**+76%**) | real 更高 |
| e_rms (roll) | 0.297 → 0.221 (+34%) | 0.243 → 0.167 (+46%) | real 更高 |
| amplitude_gain swing (roll) | **2.25** → 0.13 | 0.32 → 0.11 | real 有超调 |
| n_self_excite | **5** → 0 | 0 → 0 | real 有自激 |
| transfer_coherence | 0.04–0.18 → 0.75–0.94 | 0.01 → 0.87–0.98 | real 无线性 |
| delay_ms (roll) | 50 → 22 | -60 → -62 | 量级接近 |
| ζ_hat (pitch) | 0.082 → 0.347 | 0.103 → 0.307 | real 衰减慢 |
| A_peak (pitch) | 1.74 → 2.33 | 1.30 → 2.89 | **sim 更高** |

### 2.2 关键发现

1. **Sim 接地过冲 A_peak 反而高于 real**：这说明仿真的过刚性接触模型产生了更尖锐的冲击力，但随后被高 coherence 的 PD 控制快速压制。Real 的冲击被机械柔性缓冲吸收，但后续弹性释放因 Kd 不足而持续振荡。

2. **Real 的 transfer_coherence 极低**：频域目标→关节几乎无线性关系，说明真机的关节运动已经被非线性机制（接触冲击、弹性回弹、摩擦）主导，控制器失去有效权威。

3. **延迟量级 real 与 sim 接近**：摆动相延迟 real 76ms / sim 80ms（28号报告数据），因此延迟不是 real/sim 差异的主因。

4. **Sim 的 roll 轴 amplitude_gain 系统性远低于 1**：sim roll 0.13–0.11 vs real 2.25–0.32，说明仿真 ankle_roll 的动力学建模严重不足。

### 2.3 三因子模型验证

| 条件 | Real | Sim | 说明 |
|------|------|-----|------|
| ① 控制延迟 | ✅ ~76ms | ✅ ~80ms | **量级接近** |
| ② 机械弹性储能 | ✅ 真实传动柔性 | ❌ 刚性建模 | **核心差异 #1** |
| ③ 冲击能量注入 | ✅ 真实接触 | ❌ 过刚接触瞬时吸收 | **核心差异 #2** |

结论与 `sim2real_ankle_key_metrics_delta_summary.md` 一致：
**延迟是背景条件，但不是 real/sim 差异主因。核心差异在 ② 和 ③。**

## 三、所有参数组合的阻尼风险排名

按 ζ_theory 从低到高排序（越低的越危险）：

| 排名 | Kp/Kd | ζ_theory | Mr | PM | τ_ms | fn_Hz | 风险 |
|------|-------|----------|-----|-----|------|-------|------|
| 🔴 1 | 30/0.4 | **0.118** | 4.28 | 13.4° | 483 | 2.81 | 最差 — Kp↑ 但 Kd 不变 |
| 🔴 2 | 40/0.5 | 0.127 | 3.96 | 14.5° | 386 | 3.24 | 仿真专用，真机不会用 |
| 🔴 3 | 25/0.4 | 0.129 | 3.91 | 14.7° | 483 | 2.56 | 真机 roll 自激最多 |
| 🔴 4 | 35/0.5 | 0.136 | 3.71 | 15.5° | 386 | 3.03 | 真机右踝锁死 |

- 所有真机实测的 Kd (0.4–0.8) 均严重偏低

- 要 ζ > 0.4 需要 Kd ≈ 1.5（以 Kp=35 为例需 Kd ≈ 1.47）

## 六、建议的 Kp/Kd 调整方向

基于公式 $\zeta = K_d / (2\sqrt{K_p J_\text{eff}})$，$J_\text{eff} \approx 0.0965$：

### 6.1 短期方案（不改硬件、不改控制架构）

| Kp | 当前 Kd | 当前 ζ | 目标 ζ=0.3 需 Kd | 目标 ζ=0.4 需 Kd | 备注 |
|----|---------|--------|-------------------|-------------------|------|
| 25 | 0.4 | 0.129 | 0.93 | 1.24 | |
| 30 | 0.4 | 0.118 | 1.02 | 1.36 | |
| 35 | 0.5 | 0.136 | 1.10 | 1.47 | |
| 40 | 0.8 | 0.204 | 1.18 | 1.57 | 从 0.8→1.2 是 50% 增幅 |

### 6.2 中期方案（软件改动）

1. **Target 低通滤波**：对 touchdown 阶段的 target 做 10–15 Hz 低通，削减 38–46 Hz 的高频激励
2. **Stance/Swing 分离 Kd**：摆动相 Kd=0.8，支撑相 Kd=1.5–2.0，接地后 200ms 内用高 Kd 快速耗散冲击能量
3. **前馈 + PD 结构**：加入速度前馈补偿延迟相位损失

### 6.3 长期方案（硬件/架构）

1. **提升控制频率**：将 10ms 周期缩短到 5ms 或更低，延迟从 50–76ms 降到 20–30ms
2. **Smith 预估器**：在控制回路中建模延迟，补偿 50ms+ 延迟的相位损失
3. **专项阶跃实验**：在真机上做单关节阶跃响应，直接测量 ζ 和 fn，替代行走残差的间接估计
