Section 1
可解释的问题

以下问题均可由二阶PD系统理论定量解释，点击展开各问题的分析。

1
踝关节振荡频率为何约 3 Hz？
▶

踝关节受PD控制时，闭环系统等效为二阶系统，自然频率由刚度和惯量决定：

ωn=KpJeff,fn=ωn2π

实测踝关节等效转动惯量 Jeff≈0.0965kg\cdot m2（摆动相近似），代入各Kp值：

Kpωn (rad/s)fn (Hz)实测主频
2516.12.563.0 Hz（同频率箱）
3017.62.813.0 Hz（同频率箱）
3519.03.033.0 Hz ✓
4020.43.243.0 Hz（同频率箱）
⚠ 频率分辨率限制：采样率100 Hz、Welch窗2 s → Δf = 0.5 Hz。Kp=25–40 对应 fn=2.56–3.24 Hz，均落入同一频率箱（3.0 Hz），实测无法区分各Kp之间的差异。
✓ 3 Hz振荡是系统固有共振，并非步态频率（步态≈1.8 Hz）。Kp越大 fn越高，振荡越快但幅度受Kd控制。
2
为何 Kd 增大后振荡幅度明显减小？
▶

阻尼比 ζ 直接由 Kd 决定：

ζ=Kd2Kp·Jeff

谐振峰增益（仅当 ζ < 0.707 时存在）：

Mr=12ζ1−ζ2

Kd越大 → ζ越大 → M_r越小 → 自然频率附近的放大倍数下降：

Kp/KdζM_rPM≈100ζτ_decay (ms)
25/0.40.1293.9112.9°483
30/0.40.1184.2711.8°483
35/0.50.1363.7113.6°386
40/0.80.2042.5020.4°241
✓ Kp=40/Kd=0.8 的 ζ=0.204 最高，M_r最小（2.50），PM最大（20.4°），τ最短（241ms），实测表现最稳定。
3
M_r 的物理含义是什么？
▶

Mr 是闭环频率响应在谐振峰处的幅值增益。若输入目标中含有频率接近 ωr 的成分，该分量将被放大 Mr 倍输出到实际关节。

ωr=ωn1−2ζ2

对于 Kp=35/Kd=0.5（ζ=0.136，M_r=3.71）：

  • 步态规划器在3 Hz附近的关节目标抖动，将被放大约 3.7倍 作用于实际关节。
  • 接地冲击、地面不平整的3 Hz扰动，均产生3.7倍的过冲响应。
  • 这是踝关节在接地瞬间出现明显振铃的根本原因。
⚠ 四组参数的 ζ 均远小于 0.707，均存在谐振峰。M_r > 3 表示振荡风险显著。
4
控制延迟（约 40–60 ms）为何会恶化稳定性？
▶

纯延迟 τd 在频域中表现为随频率线性增大的相位损失：

φdelay(ω)=−ω·τd[rad]

在自然频率 ωn 处，延迟造成的相位损失（转为度）：

Δφ=ωn·τd×180∘π

以 Kp=35/Kd=0.5、延迟50 ms 为例：

计算
ωn=19.0rad/s, τd=50ms
19.0×0.05×57.3∘≈54.5∘（即约54.5°）

而该组理论相位裕度 PM ≈ 13.6°，延迟已消耗相位裕度的 4倍，实际系统相位裕度严重透支。

✓ PD微分项提供相位超前 φPD(ω)=arctan(Kd·ωKp) 在此约+15.2°，远不足以补偿54.5°的延迟损失。
5
为何 ankle_roll 左右脚振荡特性不对称？
▶

自然频率和阻尼比均依赖等效转动惯量 Jeff，而左右差异来自：

  • 机械制造公差：左右腿关节间隙、摩擦力不完全对称。
  • 接地刚度差异：左右足底压力分布不同，等效支撑刚度不同：ωn,stance=Kcontact/Jeff。
  • 静态偏置：实测 Kp=35/Kd=0.5 左脚 ankle_roll 存在约 140 mrad（8°）的静态偏差，右脚近似为零。
✓ 左脚140 mrad偏差主导FFT（DC泄漏），右脚以步态基频1.81 Hz为主，体现出不同的主导动力学。
6
增益裕度（GM）和相位裕度（PM）代表什么？
▶

相位裕度（PM）：在增益穿越频率（|G(jω)|=1）处，相角距离 −180° 的余量：

PM=180∘+∠G(jωgc)其中 |G(jωgc)|=1

增益裕度（GM）：在相位穿越频率（∠G(jω)=−180∘）处，系统增益还需放大多少倍才失稳：

GM=1|G(jωpc)|其中 ∠G(jωpc)=−180∘
⚠ 对于本征开环不稳定系统（含右半平面极点），负GM也可能稳定（奈奎斯特判据），不能仅凭GM的正负判断稳定性。

实际踝关节PD控制中，PM通常只有10–20°，远低于工程推荐值45°，这是振荡难以消除的核心原因。

7
摆动相与支撑相的自然频率为何不同？
▶
相位主导刚度特征频率
摆动相Kp（PD刚度）ωn = √(Kp/Jeff) ≈ 3 Hz
支撑相Kp + K_contactωn,stance=Kcontact/Jeff ≫ 3 Hz
✓ 地面接触刚度 Kc≫Kp（Kc 可达 10⁵ N/m），使支撑相的等效自然频率远高于摆动相。接地冲击时的振铃正是两相之间自然频率突变的瞬态响应。

Section 3 — 附录
理论依据及推导
A1
二阶PD系统标准形式 → 自然频率与阻尼比
▶

踝关节转动动力学（忽略重力和摩擦）：

原始方程
Jeffq¨=τPD+τdistτPD=−Kp(q−qd)−Kdq˙
合并为闭环方程（误差 e = q − q_d）
Jeffe¨+Kde˙+Kpe=τdist
对比二阶系统标准形式
e¨+2ζωne˙+ωn2e=τdistJeff
ωn=KpJeff,ζ=Kd2Kp·Jeff

闭环传递函数（Laplace域）：

H(s)=ωn2s2+2ζωns+ωn2
A2
谐振峰 Mr 的完整推导
▶

令 s=jω，写出幅频响应（令 u = ω/ωn）：

Step 1：幅值表达式
|H(ju)|=1(1−u2)2+(2ζu)2
Step 2：分母平方对 u² 求导，令导数为零
D=1+(4ζ2−2)u2+u4dDd(u2)=(4ζ2−2)+2u2=0⟹u2=1−2ζ2
Step 3：共振频率
ωr=ωn1−2ζ2(ζ<1/2≈0.707)
Step 4：代入 u² = 1−2ζ² 求最小分母
Dmin=2ζ1−ζ2
Mr=12ζ1−ζ2,ζ<12
  • ζ=0.136（Kp=35/Kd=0.5）：M_r = 1/(2×0.136×0.991) = 3.71
  • ζ=0.204（Kp=40/Kd=0.8）：M_r = 1/(2×0.204×0.979) = 2.50
  • ζ → 0：M_r → ∞（无阻尼，持续振荡）；ζ = 1/√2：M_r = 1（峰值消失）
A3
欠阻尼振荡衰减包络与时间常数
▶
特征根
s1,2=−ζωn±jωd,ωd=ωn1−ζ2 实部 −ζωn 为衰减率，虚部 ωd 为有阻尼振荡频率
时域响应（阶跃扰动后）
e(t)=A·e−ζωnt·sin(ωdt+ϕ)
τdecay=1ζωn=2JeffKd

A4
相位裕度 PM 与阻尼比 ζ 的关系推导
▶
开环传递函数（理想PD + 纯积分）
G(s)=ωn2(1+2ζs/ωn)s2
求增益穿越频率（令 |G| = 1，设 u = ωgc/ωn）
u4−4ζ2u2−1=0⟹u2=2ζ2+4ζ4+1
求相角 → PM
PM=arctan(2ζu)
小ζ近似（ζ ≪ 1，u ≈ 1）
PM≈arctan(2ζ)≈115ζ∘
PM≈100ζ[degrees],ζ<0.7
  • ζ=0.136 → PM≈13.6°（工程需 PM>45°，差距巨大）
  • 达到 PM=45° 需要 ζ=0.45，即 Kd = 0.45×2×√(35×0.0965) ≈ 1.66
A5
增益裕度定义与奈奎斯特判据
▶
增益裕度（GM）定义
GM=1|G(jωpc)|⇔GMdB=−20log|G(jωpc)|
  • GM > 1（GM_dB > 0）→ 稳定
  • GM = 1 → 临界稳定
  • GM < 1（GM_dB < 0）→ 不稳定（对开环稳定系统）
特殊情况：开环不稳定系统（奈奎斯特判据）
Z=N+P=0⟹closed-loop stable 其中 N 为奈奎斯特图顺时针绕 (−1, 0) 点的圈数，P 为开环右半平面极点数。 含右半平面极点时，GM<0 dB 的闭环系统可能仍是稳定的。
A6
延迟相位损失与PD相位超前的平衡
▶
纯延迟引入的相位损失（总是负）
φdelay(ω)=−ωτd[rad]=−180∘πωτd
PD微分项引入的相位超前（总是正）
φPD(ω)=arctan(Kd·ωKp) 在 ω = ωn 处：φPD(ωn)=arctan(2ζ)
净效果（Kp=35/Kd=0.5，τd=50 ms）
PD超前：arctan(2×0.136) ≈ +15.2°
延迟损失：19.0 × 0.05 × 57.3° ≈ −54.5°
净效果：−39.3°（PD无法补偿延迟）
eff. PM≈PM0+φPD(ωgc)+φdelay(ωgc)

根本解决方案：减小延迟（提升控制频率）或引入预测/Smith预估器，而非单纯调整Kd。

A7
步行中 J_eff 和 K_eff 的时变性分析
▶
时变自然频率
ωn(t)=Keff(t)Jeff(t)
各相位参数变化
  • 摆动相：J_eff ≈ 0.08–0.12 kg·m²（纯足踝惯量），K_eff = Kp
  • 支撑相（单足）：J_eff 增大2–5倍（全身质心载荷），K_eff = Kp + K_contact
  • 接地瞬间：K_contact 可达 10⁴–10⁵ N/m，使 ωn 剧增
✓ 单一Kp/Kd参数对整个步态周期不能同时最优：摆动相最优（低Kp平滑跟踪）与接地相最优（高Kd快速消散冲击）往往矛盾。可变增益控制（stance/swing切换Kd）是改善方向。
