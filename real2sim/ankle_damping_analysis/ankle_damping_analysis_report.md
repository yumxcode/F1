## 一、判定框架（v5.2）

```
┌─ 阶跃实验（悬空）？
│     YES → ζ_step 判定           ← 最可信 ★★★★★
│
├─ 时域指标（不依赖 coh，始终可用）  ← Real 端主力 ★★★★
│     amp_gain > 1.5 + 自激 > 0 → 时域确认欠阻尼（足够工程决策）
│     amp_gain > 1.0 + A_peak > 2 → 冲击放大，疑似欠阻尼
│     amp_gain < 1.0 + 自激 = 0  → 未见欠阻尼行为
│
└─ 摆动相 FRF（需 coh_sw ≥ 0.30 且 n_sw ≥ 5）
      YES → G_fn_sw 判定          ← 补充确认 ★★★
      NO  → 时域结论已足够
```

> **为什么 Real 端时域优先于 FRF？** Real 行走数据中传动间隙、摩擦、接触切换破坏了线性假设，
> coh_sw 普遍 < 0.30。但 amp_gain 和自激点不依赖线性假设，且所有 Real 端时域检出的
> 失稳事件均与阶跃实验方向一致。时域指标在 Real 端是**可信且充分**的判定工具。

## 二、最可信结论：专项阶跃实验

> 数据: `34_ankle_resonance_peak_validation.md`，对象: `right_ankle_roll`, Kp=35/Kd=0.5

| 工况 | ζ_step | 结论 |
|------|--------|------|
| 悬空 | **0.07–0.25** | 中度欠阻尼——系统固有阻尼偏低，与 ζ_th=0.136 量级一致 |
| 触地 | **0.002–0.057** | 近乎零阻尼——接触约束使衰减崩溃，恶化 10–100 倍 |

**阶跃实验是当前最可信的阻尼证据。** 每个 Kp/Kd 组合都应做悬空阶跃实验（10 分钟/组）。

### 4.2 FRF 补充确认（coh_sw ≥ 0.30 且 n_sw ≥ 5）

Real 端满足此条件的案例极少。以下是全部合格案例：

**FRF 结论**：Real 行走数据摆动相片段太少（n_sw=0–4），无法获得统计可靠的 FRF 估计。
这不是方法缺陷，是数据时长不足。需要更长的行走日志或 sine-sweep 实验。

### 最终结论

1. **方法有效**：三层框架各自在有效范围内给出了明确结论。
   Real 端 "无法判定" 的比例高不是方法失效，而是数据质量限制（n_sw 太少）。
   在有时域指标的场景下，**时域结论已足够支撑工程决策**。

2. **Real 欠阻尼证据链完整**：
   - 阶跃实验（35/0.5）：最可信的直接证据
   - 时域指标（25/0.4, 30/0.4, 40/0.8）：3 个高置信失稳事件，与阶跃方向一致
   - 全步态 FRF（40/0.8 R side）：G_fn=1.19–2.00, coh=0.60–0.90，交叉验证

3. **Sim 过阻尼（结论不变）**：ζ_sw=0.71–5.7，实际阻尼是 ζ_th 的 15–23 倍。

4. **下一步优先级**：
   - 补阶跃实验（每个 Kp/Kd → 10 分钟/组）——最高 ROI
   - 延长行走日志时长（目标 n_sw ≥ 20）——提升 FRF 可用性
   - Sine-sweep 实验补充宽带激励——替代行走数据做 FRF
