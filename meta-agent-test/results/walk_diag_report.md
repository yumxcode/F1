# 高速行走不稳 — 诊断分析报告

**数据文件**: `walk_diag_20260523_152341.csv`  
**分析日期**: 2026-05-26  
**数据规模**: 1000帧, ~100Hz采样率, 133列/帧

---

## 1. 假设条件

- 数据来自sim2real测试或仿真环境（接触传感器始终为0）
- `cmd_linear_x`: 0 → 0.8 m/s 阶跃指令
- `pos_des_raw_*`: 期望关节位置（规划器输出）
- `pos_*`: 实际关节位置（编码器反馈）
- `effort_*`: 关节力矩/力（单位暂定为Nm，待确认）
- `action_*`: 控制指令（发送给执行器）
- `is_parallel=0`: 表示关节处于**串联控制模式**（非并联）；踝关节=1表示并联模式

## 3. 核心诊断发现

### 3.1 机器人完全失稳 — 3.6秒处发生崩溃

在 t≈3.58s (frame 358)，机器人出现剧烈失稳：

| 时刻 | 事件 |
|------|------|
| t=0.0s | 速度0→0.8 m/s 阶跃 |
| t=3.4s | yaw角速度 `ω_z` 达到 +2.95 rad/s，roll角剧烈震荡 |
| t=3.58s | `ω_z` 骤降至 -0.01 rad/s，标志着失稳 |
| t=3.6–3.7s | `ω_z` 达到 **-3.75 rad/s**，yaw剧烈回摆 |
| t=6.0–9.9s | 所有base角速度和姿态**完全冻结**（std=0），表明机器人已倾倒/数据无效 |

### 3.2 Yaw漂移 — 失稳的主要表现

| 阶段 | Yaw范围 | ω_z 范围 |
|------|---------|----------|
| 早期 (0–3.3s) | 0.49→0.07 rad | std=1.07 rad/s, max=3.67 |
| 中期 (3.3–6.6s) | 0.33→-0.14 rad | std=0.89 rad/s, max=4.07 |
| 后期 (6.6–9.9s) | 固定-0.143 rad | 固定-0.331 rad/s |

**yaw漂移速率**: **-0.064 rad/s (-3.65 deg/s)**，持续向左偏转。

### 3.3 关节跟踪误差 — 所有关节严重滞后

所有髋/膝关节的跟踪误差均超过 0.3 rad：

| 关节 | 平均误差(rad) | 最大误差(rad) |
|------|:---:|:---:|
| **右膝 pitch** | **0.725** | 1.830 |
| **左髋 pitch** | **0.679** | 2.041 |
| **右髋 pitch** | **0.577** | 2.639 |
| 左膝 pitch | 0.552 | 1.417 |
| **左髋 roll** | **0.439** | 1.716 |
| 右髋 roll | 0.353 | 1.645 |
| 左髋 yaw | 0.366 | 1.487 |
| 右髋 yaw | 0.311 | 1.154 |

> 踝关节跟踪相对较好（0.16–0.28 rad），因为踝关节处于`is_parallel=1`（并联控制）模式。

### 3.4 控制模式不对称 — is_parallel标志揭示关键问题

| 关节组 | is_parallel | 含义 |
|--------|:---:|------|
| 髋部+膝部 (8个关节) | **0** | 串联控制 |
| 踝部 (4个关节) | **1** | 并联控制 |

**串联控制的8个关节**全部存在：`tau_des_raw` 和 `tau_des_lpf` 列**全为NaN**，且`pos_des_lpf`全为NaN。这意味着：
- 串联控制链路中**前馈力矩通道完全缺失**
- 位置指令的LPF（低通滤波平滑）也缺失
- 踝关节（并联模式）有完整的 `pos_des_lpf` 数据

### 3.5 左右不对称

| 指标 | 左侧 | 右侧 | 差值 |
|------|:---:|:---:|:---:|
| 髋 pitch 平均力矩 | 21.1 | **32.3** | -42.2% |
| 膝 pitch 平均力矩 | 14.5 | **34.5** | -81.4% |
| 踝 pitch 平均力矩 | 3.0 | **6.3** | -71.5% |
| 髋 roll 平均力矩 | 13.2 | 16.0 | -18.6% |

**右侧承受显著更大的负载**（特别是膝和踝关节），这与yaw向左漂移一致 → 右侧支撑更多。

### 3.6 失稳时间线（逐段）

| 时间段 | ω_x std | ω_y std | ω_z std | 状态 |
|--------|:---:|:---:|:---:|------|
| 0–3.3s (早期) | 0.711 | 0.694 | 1.072 | 震荡逐步加剧 |

| 6.6–9.9s (后期) | ~0 | ~0 | ~0 | 机器人已倒下 |

## 4. 根因分析

### 主要根因：**串联控制模式下前馈力矩缺失 + 高速阶跃指令**

1. **指令阶跃冲击**：速度从0跳到0.8 m/s，无加速过渡，对控制系统造成瞬时大扰动

2. **前馈力矩缺失**：8个髋/膝关节的 `tau_des_raw`/`tau_des_lpf` 全为NaN → 纯反馈位置控制，缺乏动力学前馈补偿。在高速下，惯性和科里奥利力效应显著增大，纯反馈无法及时补偿

3. **位置LPF缺失**：`pos_des_lpf` 全为NaN → 期望轨迹未经平滑，可能存在高频分量激发振荡

4. **Hip Roll通道崩溃是导火索**：失稳起始于yaw方向振荡（ω_z在3.4s达到+2.95 rad/s），触发 hip roll 的剧烈对抗（action从+0.46突变到-3.77），最终所有角速度在~3.58s崩溃

5. **左右负载不对称**：右侧比左侧多承受42-81%的力矩 → 机器人偏向一侧，加剧yaw漂移

### 级联失效链：
```
0.8 m/s阶跃 → 纯反馈控制滞后 → yaw震荡 → hip_roll大动作对抗 
→ roll/pitch失控 → 3.58s完全失稳 → 3.7s yaw回摆4.07 rad/s → 倾倒
```

---

## 5. 建议措施

### 短期（立即可做）
1. **增加速度斜坡**：将 `cmd_linear_x` 阶跃改为 ramp (0.5–1.0s 过渡)
2. **修复前馈力矩**：检查为何 `tau_des_raw` 全为NaN — 确认规划器是否输出了前馈力矩
3. **补全 pos_des_lpf**：确保所有关节的位置指令经过低通滤波

### 中期
4. **串联-并联模式统一**：评估是否所有关节都应该迁移到并联控制（踝关节表现明显更好）
5. **调整hip roll控制器增益**：hip roll tracking error过大(0.44 rad)，需要增大位置/速度增益
6. **平衡左右负载**：检查运动学/步态参数，是否存在不对称导致右侧过多负载

### 长期
7. **引入MPC/全身控制(WBC)**：替换纯反馈+前馈架构，在高速下实现更好的协调控制
8. **增加失稳检测与保护**：在 ω_z > 2.0 rad/s 时触发保护性降速或紧急停止
