# T27 真机行走故障诊断报告

**日期**: 2026-05-19  
**数据**: `test_logs/data_csv/t27_joint_20260518_1_real.csv`  
**硬件**: X1 (R52/R86-2/R86-3, 12DOF)

---

## 核心发现: Hip Roll 通道失效级联

> **根因**: Hip Roll PD低层控制器完全失效 → 侧向稳定丧失 → 接触不对称 → Yaw漂移 → 完全失稳

### 数据量化摘要

| 指标 | 左Hip Roll | 右Hip Roll | 正常应有值 |
|---|---|---|---|
| action↔pos 相关性 | **+0.0334** (≈0) | **-0.1764** (负相关!) | >0.7 |
| action↔pos_des_raw 相关性 | +0.9782 ✓ | +0.9929 ✓ | >0.95 |
| pos_des_raw↔pos 相关性 | **+0.0109** (≈0) | **-0.1862** | >0.7 |
| 追踪比(pos/action) | **3.5%** | **5.1%** | >50% |
| Effort范围 | -75~+24.7 Nm | -21.3~+65.8 Nm | — |

### 级联故障路径 (4步)

```
Step 1: Hip Roll PD追踪失效
  ├─ pos_des_raw正确生成(action↔pos_des_raw corr=0.98~0.99)
  └─ ❌ 低层PD无法将pos_des_raw转化为实际位置(pos_des_raw↔pos corr≈0)
       → 左腿HipRoll实际位置锁定在[-0.09, 0.11]rad，不动弹

Step 2: 侧向稳定丧失
  └─ HipRoll不响应策略输出的侧向力矩需求
       → 左腿逐渐失去支撑能力

Step 3: 接触不对称
  ├─ 左腿接触率: 13.6% (初始33%→最终0%)
  ├─ 右腿接触率: 66.9%
  ├─ 双足支撑: 仅有 4.6%
  └─ 62.3%时间: 仅右腿着地 + 24%腾空

Step 4: Yaw漂移 / 完全失稳
  ├─ Yaw漂移: 40.3°/20s
  ├─ 最大Yaw角速度: 3.31 rad/s
  └─ 最终状态: 右腿单腿跳跃，左腿悬空
```

---

## 详细分析

### 1. 控制链路审计

从RL策略输出(action)到实际关节位置(pos)的完整链路：

```
action (策略输出) ──[action_scale=0.5 + offset]──→ pos_des_raw ──[PD控制器]──→ pos (实际位置)
                        corr=0.98~0.99 ✓                corr=0.01~-0.19 ❌
```

**转换层正常**: `pos_des_raw = offset + 0.4~0.5 × action`  
**PD层失效**: 即使position error达到1.5 rad，电机仍不动作

### 2. 配置审计

从 `rl_x1.yaml` 提取的当前行走配置:

| 参数 | 当前值 | 原版(注释) | 建议值 |
|---|---|---|---|
| HipRoll Kp | **45** | 40 | **80~120** |
| HipRoll Kd | **3.0** | 3.0 | **5.0~8.0** |
| HipPitch Kp | 45 | 30 | 60~80 |
| KneePitch Kp | 80 | 100 | 100 |
| cycle_time | **0.55s** | **0.7s** | **0.7s** |
| action_scale | 0.5 | 0.5 | 0.5 |
| 力矩前馈 | 仅踝关节 | 仅踝关节 | **扩展至髋/膝** |

### 3. 关节类型差异

| 类型 | is_parallel | 控制模式 | 关节 | 力矩前馈 |
|---|---|---|---|---|
| **并联关节** | 1 | 位置+力矩前馈 | 踝关节 | ✅ 有 |
| **非并联关节** | 0 | 纯PD位置控制 | 髋/膝关节 | ❌ 无 |

踝关节(并联, is_parallel=1)的tau_des_raw/lpf有数据，追踪相对较好。  
髋关节(非并联, is_parallel=0)的tau_des_raw/lpf全为NaN，完全依靠PD位置控制。

### 4. 所有关节Action-Position相关性排序

| 关节 | 相关性 | 追踪比 | 状态 |
|---|---|---|---|
| right_ankle_pitch | **+0.5119** | 6.2% | ⚠ 可追踪但幅度不足 |
| right_ankle_roll | +0.3407 | 24.8% | ⚠ 部分跟踪 |
| left_ankle_roll | +0.2539 | 15.8% | ⚠ 部分跟踪 |
| right_hip_pitch | +0.1871 | 11.5% | ⚠ 弱跟踪 |
| right_hip_yaw | +0.1477 | 18.0% | ⚠ 弱跟踪 |
| left_knee_pitch | +0.1421 | 19.6% | ⚠ 弱跟踪 |
| left_hip_pitch | +0.0899 | 8.2% | ❌ 几乎不跟踪 |
| left_hip_yaw | -0.0952 | 12.3% | ❌ 反向/不跟踪 |
| right_hip_roll | **-0.1764** | 5.1% | ❌ 反向/不跟踪 |
| left_ankle_pitch | -0.2251 | 5.9% | ❌ 反向/不跟踪 |
| right_knee_pitch | **-0.3174** | 34.0% | ❌ 负相关 |
| left_hip_roll | **+0.0334** | **3.5%** | ❌ **最差，几乎为零** |

> **结论**: 所有关节的跟踪都差，但Hip Roll最严重（几乎为零跟踪）。

## 修复建议

### 🚨 P0 — 立即执行

| 优先级 | 修改项 | 当前值 | 建议值 | 原理 |
|---|---|---|---|---|
| P0 | **HipRoll Kp** | 45 | **100+** | 提高位置误差到力矩的增益，克服重力负载 |
| P0 | **cycle_time** | 0.55s | **0.7s** | 降低步态频率，给PD控制器更多响应时间 |
| P0 | **HipRoll Kd** | 3.0 | **6.0~8.0** | 增加阻尼，抑制震荡 |

### 📋 P1 — 建议实施

| 优先级 | 修改项 | 当前值 | 建议值 | 原理 |
|---|---|---|---|---|
| P1 | 所有腿部关节Kp均匀提升 | 30~80 | **×1.5~2.0** | 整体PD增益偏低 |
| P1 | Hip/Knee关节力矩前馈 | 无 | **添加** | 参考踝关节实现，扩展paralle_list |
| P1 | HipRoll action输出限幅 | ±4.4~5.9 rad | **±2.0 rad** | 实际关节限位仅±0.2~1.5 rad，过大action浪费力矩 |
| P1 | 回退原版Kp配置 | 当前(1.2m/s) | 原版配置 | 原版Knee Kp=100, HipRoll Kp=40更保守 |

### 🔬 P2 — 深入调查

| 优先级 | 修改项 | 说明 |
|---|---|---|
| P2 | 做hip_roll阶跃响应测试 | 在机器人悬挂/站立状态下，给hip_roll发阶跃位置指令，测量实际响应速度和稳态误差 |
| P2 | sim2real PD增益校准 | 确认sim中的PD表现是否与real一致；如果不一致，需在real端独立标定 |
| P2 | 检查R86执行器力矩上限 | 确认力矩输出是否达到驱动器限流，或是机械传动间隙问题 |
