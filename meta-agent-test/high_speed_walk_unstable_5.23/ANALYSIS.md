### 4.3 关键发现

1. **第一步 (S0) hip roll 跟踪反而是最好的** — target 在 TD 时要求外展，position 几乎完美跟上 (gap −0.002 rad)
2. **冲突的充要条件: target 在 TD 时要求内收 (adduct)**
   - 要求外展的步 (S0/S3/S4): 跟踪 OK，gap 仅 0~8°
   - 要求内收的步 (S1/S2/S5/S6/S7): position 无一例外无法跟上
3. **问题随步数恶化**: S1 gap −20° → S5 gap −41° → S6 gap −45° → S7 gap −48°
4. **raw target LO-SAT 是冲突步的标志**: 4 个冲突步中 3 个 raw target 撞 −1.50 下限位
5. **最大 gap 达 −1.65 rad (−94°)**: S6 时 raw target LO-SAT，lpf 被拉到 −1.48，但 position 停在 +0.15

### 4.4 根因

**Hip roll 执行器在负载下向内收方向驱动的能力不足。** Target 要求回到中线（甚至内收），但电机/传动链在着地冲击和体重负载下推不回去。这不是延时问题 (best delay 150ms)，延时只能解释 5-15° 滞后，不能解释 40-94° 的方向性背离。

## 7. 结论

### 7.1 崩溃链条

```
0.8 m/s 高速直行
    │
    ├─ target 大量撞击限位 (hip_roll 双端, ankle_pitch 双端, 共4关节)
    ├─ tau_des 全 NaN (前馈力矩路径失效)

    │
    └─ t=4.82s: 全部12关节同时锁死 → 电机保护/饱和
```

### 7.2 分级结论

| 级别 | 发现 | 证据 |
|---|---|---|
| **确定** | 0.8 m/s 下 4.8s 必然崩溃 | 全关节锁死，effort 非零但位置不变 |
| **确定** | Hip roll 内收方向响应失效 (间歇性) | 4/10 swings target 要内收时 pos 无法跟上，gap 达 20–45° |
| **确定** | Ankle pitch raw target 大幅超限 | bang-bang 在 [−0.41, +0.35]，70% 时间在限位上 |
| **确定** | tau_des 全 NaN — 前馈路径失效 | 所有关节 tau_des_raw/lpf 列全部 NaN |
| **可能** | contact=0 导致策略无着地反馈 | 全程无接触检测信号 |

### 7.3 建议

1. **不要继续在 0.8 m/s 当前参数下试跑**
2. **排查 tau_des 全部 NaN 的原因** — 串联控制的前馈力矩路径为何完全失效
3. **排查 ankle pitch raw target 溢出** — 为何在高速时 raw target 在 ±0.41/0.35 之间 bang-bang (限位 5 倍?)
4. **排查 hip roll 执行器内收能力** — 为何 target 要求内收时电机推不动
5. **排查 contact 检测** — 全程为 0 且无跳变，阈值/逻辑需验证
