## 3. 外翻来源分解: Target vs Position

| 伸展 (0.55-0.67s) | | +0.15 (+8°) 外展→ | +0.09 (+5°) 外展 | +3° | 跟踪尚可 |

## 5. 结论

```
着地时左腿外翻 = HIP ROLL 响应滞后 + ANKLE ROLL target 过度外翻

  HIP_ROLL:
    Target 在着地瞬间正确翻转为内收 (−17°)
    但 Position 来不及响应，卡在 +8° 外展
    → 纯执行问题 (电机推不动)

  ANKLE_ROLL:
    Target 在着地时要求 +31° 外翻 — 本身就过度
    Position 跟到 +12° — 部分跟上但仍然偏大
    → Target 生成问题 + 执行滞后 (双重)
```

**修正方向:**
- Hip roll: 提升内收方向的执行能力 (检查 effort 是否饱和 — p95 = 54 Nm，着地时可能不够)
- Ankle roll: 排查为何 raw target 在着地时推到 +31° 外翻 — 需要查 action scale 或策略输出的 ankle roll 映射
