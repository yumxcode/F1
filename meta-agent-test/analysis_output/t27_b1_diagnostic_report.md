# T27 B1 新数据 4步级联故障诊断报告 (修正版)

**日期**: 2026-05-20
**数据**: `t27_tracking_lag_b1_diag_20260520_165013.csv`
**硬件**: X1 (R52/R86-2/R86-3, 12DOF)

---

## 核心发现: PD增益不足 → 140-170ms相位滞后 → 侧倾累积 → 4秒倒塌

> **根因**: 腿部关节PD追踪增益普遍偏低(追踪比仅5-35%)，存在140-170ms控制延迟。
> 零滞后相关性为负 ≠ PD方向反了，而是因为相位滞后 + 追踪幅度极低的综合效果。
> **经互相关延迟校正后，6/12关节最佳滞后相关性 >0.4，证明PD方向正确但增益不足。**
> 机器人在0-4秒内roll角从+0.01累积到+0.18 rad (≈10.5°)，3.5-4.0秒间倒塌。

### 关键修正 (vs 初版分析)

| 初版错误结论 | 修正后结论 |
|------------|----------|
| "PD反向驱动，8关节负相关" | **PD方向正确，负相关来自相位滞后 + 低增益** |
| "R_HipR corr=-0.467" | 最佳滞后corr仅-0.286（追踪仍然很差，但不是方向反了） |
| "系统级控制律符号错误" | **不是符号问题，是增益问题** |

## 结论与建议

### 故障机制 (修正后)

```
Step 1: PD增益不足 + 控制延迟
  ├─ 6/12关节方向正确但增益低 (追踪比 5-35%)
  ├─ 3个关键关节完全失效: R_HipR, R_HipP, R_AnkR
  └─ 140-170ms相位滞后普遍存在

Step 2: 侧倾累积
  ├─ 0-1s: 59次roll突变 → 持续向右倾斜
  ├─ R_HipR追踪失败 → 侧向力矩无法建立
  └─ t=3.5s: roll达到0.184rad → 失稳

Step 3: 倒塌
  ├─ R_Knee输出85.7Nm, L_HipR输出44.0Nm
  └─ t=4s: 机器人完全失稳, 侧倒在地

Step 4: 静止
  ├─ 4-40s: 双足100%着地, 所有effort≈0, 关节锁定
  └─ AngVel Z恒定1.564 → 传感器疑点
```

### 建议

1. **P0 — R_HipR,R_HipP,R_AnkR专项排查**: 与L_HipR(同配置,工作正常)对比，这三关节为何追踪完全失效。重点检查:
   - 机械装配/传动间隙是否正常
   - 编码器反馈是否正确
   - 电机力矩输出是否正常(排除限流/故障)

2. **P0 — 检查 AngVel Z 传感器**: 4-40s期间值恒定1.564不变，需排查陀螺仪或数据采集链路。

3. **P1 — 提高PD增益**: 全局追踪比仅5-35%，需将Kp从当前值翻倍。优先处理L_HipR(已可用)→推及所有关节。

4. **P1 — 降低步态速度**: 当前cmd_linear_x=0.799 m/s过快，建议先以 0.3-0.5 m/s 验证基础控制后再加速。

5. **P2 — 降低cycle_time**: 从0.55s回退到0.7s，给PD控制器更多响应时间补偿140-170ms延迟。
