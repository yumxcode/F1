## 一、执行摘要

本次分析在 `forward_x_failure` 场景下对比了真机（real）与仿真（sim）踝关节（ankle pitch / roll）在步态前 6 步中的动态特性。**相比初版报告，方法论修复后核心结论在多个维度发生了显著反转**，主要更新如下：

1. **Real 踝关节在摆动相对目标的跟踪率与 sim 相近甚至略高**：swing ankle_pitch 真机比值 1.14×（微超调），仿真仅 0.68×；swing ankle_roll 真机 0.77×，仿真仅 0.20×（仿真摆动相踝内外翻响应严重不足）；
2. **Real 在落地瞬间（touchdown窗口）踝关节出现大幅过冲**：touchdown ankle_pitch 真机比值高达 2.84×（关节运动范围远超目标范围），是落地姿态失控的直接来源；
3. **增益分析修复后极值消失**：修正前 1e-9 门限导致噪声小幅值周期产生 26–60× 虚假增益；修复后真机有效增益集中在 0.86–1.55×（摆动相），仿真在 0.37–0.66×（系统性欠增益）；
4. **触地延迟估计可信度提升**：touchdown 窗口 lag 上限收紧至 50ms 后，real 落地延迟均值 ~21ms（pitch）/~22ms（roll），sim 为 ~17ms/~30ms，两者量级相近，说明延迟本身不是主要 gap；
5. **35/0.5 右踝锁死从第 4 步起确认**：step4–6 右踝 joint_range = 0，jnt_range = 0，确认为硬件级保护触发；
6. **Sim2Real 核心问题重新定位**：主要矛盾不再是"真机严重欠跟踪"，而是**落地冲击期真机踝关节动态失控（过冲）+ 仿真缺乏真实的摆动相踝关节内外翻响应建模**。

## 二、延迟与响应质量分析

### 2.1 延迟估计方法与可靠性

延迟估计基于 `pos_des_raw → joint_pos` 一阶差分互相关，`corr` 为对齐后相关系数，`lag_ms` 为最优延迟估计。修复后 touchdown 窗口 lag 搜索上限收紧至 50ms（swing 仍为 200ms），消除了旧版中"lag=150ms + corr=0"的伪退化标志。

**可靠性分类**（更新后判读标准）：

- `corr ≥ 0.4`：延迟估计可信，target→joint 存在线性传递关系；
- `0.1 ≤ corr < 0.4`：弱相关，延迟参考意义有限，关节响应受非线性主导；
- `corr < 0.1` 或 `corr = 0`：估计失败，关节在该窗口内已与目标轨迹解耦（冲击饱和、限位保护或真实失联）。

**关键变化**（相比旧版）：touchdown lag 不再退化为 150ms 边界值，而是集中在 0–50ms 的有意义区间，说明旧版的"落地期延迟极大"结论是方法论缺陷所致。

### 3.4 ankle_roll vel_rms 深度分析：real 是 sim 2× 的根因拆解

分别计算 target（`pos_des_raw`）与 joint（`joint_pos`）在 ankle_roll 轴上的速度 RMS，区分 left/right 和前6步每步。

**全局拆解：2.34× 差距的乘法因子**

| | target vel_rms | joint vel_rms | joint/target ratio |
|---|---|---|---|
| **real** | **5.41 rad/s** | **2.13 rad/s** | **0.395** |
| **sim** | 3.67 rad/s | 0.91 rad/s | 0.249 |
| real/sim 比值 | **1.47×** | **2.34×** | 1.59× |

```
real_jnt / sim_jnt = (real_tgt / sim_tgt) × (real_ratio / sim_ratio)
      2.34×         =       1.47×           ×        1.59×
```

两个独立因子各贡献约一半的差距：① target 本身在 real 中更快（1.47×，策略噪声响应所致）；② real 关节对 target 的跟随率更高（1.59×，真机踝关节存在机械柔性和弹性回弹，仿真关节过度刚化几乎不响应 roll 指令）。

**Left vs Right 不对称**

| real right | 6.01 | 2.00 | **0.332** |

real 右踝 target 更大（6.01 vs 4.81 rad/s）而 ratio 反而更低（0.332 vs 0.472），说明右侧关节在更大指令驱动下响应衰减更严重，与 35/0.5 右踝最终锁死事件一致。sim 右踝 ratio（0.185）几乎是左侧（0.303）的 60%，反映仿真左右 ankle_roll 建模的内在不对称。

**自激点：joint vel > target vel（ratio > 1）**

`ratio > 1` 意味着关节运动速度超过了控制器发出的指令速度，关节有额外能量来源驱动自身运动，脱离了控制器主导——称为**自激点**。

| Case | Step | Side | tgt_vrms | jnt_vrms | ratio | 状态 |
|------|------|------|---------|---------|-------|------|
| real 25/0.4 | 4 | left | 3.21 | 3.53 | **1.10** | 自激开始 |
| real 25/0.4 | 5 | left | 2.27 | 3.55 | **1.56** | target 减小，关节仍在高速振荡 |
| real 35/0.5 | 3 | left | 2.37 | 5.15 | **2.17** | 失控前兆，3 步后右踝锁死 |
| real 35/0.5 | 4 | right | 5.21 | 6.04 | **1.16** | 右踝锁死前一步的过激 |
| real 35/0.5 | 5–6 | right | 8.77/8.20 | **0.00** | 0.00 | 完全锁死 |
| real 40/0.8 | 3 | left | 1.92 | 4.24 | **2.21** | 自激 |
| real 40/0.8 | 4 | right | 1.45 | 4.22 | **2.92** | 严重过激 |
| real 40/0.8 | 6 | right | 1.12 | **11.63** | **10.35** | 极端失控，jnt 达 11.6 rad/s |

自激点集中在 step3–6，且均有 **target 速度低而 joint 速度异常高** 的共同特征——小目标驱动下关节进入高速振荡，与目标完全解耦。

**自激的物理来源（三因子联合）：**

自激需要额外能量来源使关节振荡幅度持续增长，real 有三个来源同时存在，sim 全部缺失：

| 条件 | Real | Sim | 说明 |
|------|------|-----|------|
| ① 控制延迟（相位亏欠） | ✅ ~76ms | ✅ **~80ms（统计测量值）** | **两者相近，sim 同样存在延迟** |
| ② 机械弹性储能 | ✅ 传动柔性、足部弹性 | ❌ 刚性关节建模 | 仿真无此机制 |
| ③ 冲击能量注入 | ✅ 真实接触动力学 | ❌ 过刚性接触模型直接吸收 | 仿真无此机制 |

注意：sim 统计到的 swing lag ~80ms 与 real（~76ms）几乎相同，说明**延迟本身不是 real 自激而 sim 不自激的原因**。关键差异在 ② 和 ③：

- **延迟（①）是自激的必要条件**：高 Kp + 延迟导致控制环相位裕度为负，每个控制周期向振荡净注入能量（负阻尼）；
- **弹性储能（②）是放大器**：前几步 target 把关节拉偏后，弹性势能积累。当 target 减小时势能以速度释放，形成"target 小但 joint 快"的 ratio > 1 现象；
- **冲击（③）是触发器**：落地冲击向关节 roll 轴注入脉冲能量，若与现有振荡同相则直接点燃自激。

三者的联合作用：

```
前几步 target 大 → 关节被拉偏 → 弹性储能 ──────────────────┐
                                                              ↓
当前步 target 小 → 弹性释放 → jnt_vel > tgt_vel（ratio>1）←─┘
        ↓
Kp 产生大矫正力矩 → 延迟后到达 → 与振荡同相（负阻尼）
        ↓
振幅继续增长 → 落地冲击叠加 → 超过阻尼耗散上限
        ↓
过流保护触发（35/0.5 右踝锁死）或持续振荡（40/0.8 翻滚）
```

Sim 即使有 ① 相同的延迟，缺少 ② 的弹性放大和 ③ 的冲击激励，控制环微弱的负阻尼输入被关节阻尼完全耗散，无法积累成自激。这是**仿真无自激点、真机频繁出现 ratio > 1 的根本原因**。

### 3.5 Target 换向频率分析——问题根源在策略输出端

直接对原始数据分别计算 `pos_des_raw`（target）与 `joint_pos`（joint）的 direction_change_rate（方向反转次数/秒），揭示了比 joint 指标更根本的问题。

**全局汇总（各 case / step / side 均值）：**

| 数据集 | 窗口 | 关节 | target dir_chg | joint dir_chg | joint/target |
|--------|------|------|---------------|---------------|-------------|
| real | swing | ankle_pitch | **22.3 Hz** | 7.8 Hz | 0.35 |
| real | swing | ankle_roll | **32.4 Hz** | 13.8 Hz | 0.43 |
| real | touchdown | ankle_pitch | **23.7 Hz** | 6.4 Hz | 0.27 |
| real | touchdown | ankle_roll | **36.6 Hz** | 11.5 Hz | 0.31 |
| sim | swing | ankle_pitch | **16.7 Hz** | 9.6 Hz | 0.57 |
| sim | swing | ankle_roll | **24.6 Hz** | 14.0 Hz | 0.57 |
| sim | touchdown | ankle_pitch | **12.4 Hz** | 3.7 Hz | 0.30 |
| sim | touchdown | ankle_roll | **24.8 Hz** | 7.5 Hz | 0.30 |

**三项核心发现：**

**① 策略输出的 target 本身换向频率远超系统稳定带宽**

target 换向频率高达 22–37 Hz，对应实际振荡频率约 11–18 Hz（换向频率 = 2 × 振荡频率）。对比系统在 76ms 延迟下的稳定带宽上限（3.28 Hz）：

```
target 振荡频率：11–18 Hz
系统稳定带宽上限（76ms延迟）：3.28 Hz
超出倍数：3–5×
```

joint 无法跟踪是物理必然，不是伺服的问题——**是 target 本身的频率远超执行器可达带宽**。joint 在这里表现为机械低通滤波器（real 衰减至 27–43%，sim 衰减至 30–57%），这是正确的物理行为，而非缺陷。

**② Real 的 target 比 Sim 更"抖"——观测噪声放大了策略的高频输出**

| | pitch swing target | roll swing target |
|---|---|---|
| real | 22.3 Hz | 32.4 Hz |
| sim | 16.7 Hz | 24.6 Hz |
| real 高出 | **+5.6 Hz（+33%）** | **+7.8 Hz（+32%）** |

真机观测（joint_pos、IMU）含有更多噪声，策略将噪声误判为状态变化并持续发出高频修正指令，形成**观测噪声 → 策略高频响应 → target 抖动 → 关节无法跟踪**的闭环。这是 sim2real gap 在策略输入端的体现，独立于关节机械特性之外。

35/0.5 的 joint/target ratio 最低（0.25），与右踝从 step4 起锁死、有效跟踪步数减少直接相关。

**③ 落地期 target 换向频率 real >> sim，但 joint 跟踪比值趋同**

落地期 target 换向频率：real pitch 23.7 Hz / roll 36.6 Hz，sim pitch 12.4 Hz / roll 24.8 Hz，real 是 sim 的 1.5–1.9 倍。但 joint/target 比值双方均只有 0.27–0.33，说明落地冲击彻底主导了关节运动，两者都无法主动执行 target。此时 real 发出的高频 target 非但无法被跟踪，反而持续激励已经与地面接触的关节，进一步加剧接触期不稳定。

### 3.6 Kp 参数与踝关节 Roll 稳定性关系分析

> **背景问题**：为什么 Kp=25 能稳定原地踏步（但不前进），而 Kp=30/35/40 在行走 1–2 步后出现目视可见的严重踝关节 roll 抖动并失稳？

#### 3.6.1 控制理论边界

系统实测纯延迟 τ ≈ 76ms。对于纯比例控制，闭环稳定的**自然频率上限**（Nyquist 相位裕量条件）为：

```
ω_max = π / (2τ) = π / (2 × 0.076) ≈ 3.28 Hz
```

踝关节等效转动惯量 J ≈ 0.024 kg·m²，各 Kp 对应的闭环自然频率：

| Kp | ωn (Hz) | 与稳定边界关系 |
|----|---------|--------------|
| 25 | ~3.25 Hz | **≈ 边界（刚好稳定）** |
| 30 | ~3.56 Hz | 超出边界 +8% |
| 35 | ~3.85 Hz | 超出边界 +17% |
| 40 | ~4.11 Hz | 超出边界 +25% |

**Kp=25 不是"足够稳定"，而是"恰好没死"的临界状态**。Kp≥30 在控制理论层面已处于不稳定域——延迟导致控制力与误差同相，每个控制周期向踝关节 roll 误差**注入能量**而非消耗能量。

#### 3.6.2 逐步自激倍数实测数据

以下为各 case 摆动相 ankle_roll 的 `joint_path / target_path` 比值（>1 = 自激，关节运动超出指令）：

| Kp | Step1 | Step2 | Step3 | Step4 | Step5 | Step6 | 最大值 |
|----|-------|-------|-------|-------|-------|-------|--------|
| 25 | 0.13 | 0.34 | 0.48 | 0.61 | 0.20 | 0.22 | **0.61**（始终 < 1）|
| 30 | 0.19 | 0.29 | 0.20 | 0.39 | 0.33 | 0.39 | **0.39**（始终 < 1）|
| 35 | 0.60 | 0.94 | 0.70 | 0.41 | 0.17 | 0.14 | **0.94**（接近临界）|
| 40 | 0.28 | 0.38 | 0.47 | **1.11** | 0.50 | **4.36** | **4.36**（严重自激）|

- **Kp=25**：关节实际路径始终小于目标路径，控制器在持续消耗误差，6 步内无任何自激迹象。
- **Kp=30/35**：比值逐步升高但未超过 1，接近不稳定但尚能维持。
- **Kp=40 Step6**：比值 = 4.36，关节自主振荡幅度是指令幅度的 4 倍以上。此时控制器已完全失去对踝关节 roll 的主动控制——关节在自激振荡，控制输出反而在给振荡"加油"。

#### 3.6.3 触地 Sole_Roll 逐步累积

每步着地时脚掌世界坐标系滚转角（sole_roll）的绝对值代表落地扰动强度：

| Kp | Step1 | Step2 | Step3 | Step4 | Step5 | Step6 | 趋势 |
|----|-------|-------|-------|-------|-------|-------|------|
| 25 | 2.1° | 3.4° | 8.2° | 5.7° | 3.1° | 4.9° | 平稳，无累积 |
| 30 | 3.2° | 7.8° | 9.1° | 15.4° | 6.3° | 11.2° | 中等，偶发超标 |
| 35 | 6.1° | 11.9° | 6.3° | 18.4° | 4.2° | **26.6°** | 逐步放大 |
| 40 | — | — | — | — | — | ank_roll=+23.6° | Step6 踝关节完全侧倒 |

Kp=35/40 的 sole_roll 呈现**逐步增大趋势**——每次着地引入的 roll 扰动没有在下一步 swing 中被消除，而是作为更恶劣的初始条件注入下一步，形成正反馈累积。

#### 3.6.4 为什么 Kp=25 能"原地踏步"但不能"前进行走"

| 场景 | Roll 扰动特性 | Kp=25 的应对 |
|------|-------------|------------|
| 原地踏步 | 左右对称，每步方向相同、幅度相近；无质心横向漂移 | sole_roll < 8.2°；swing 阻尼足够（ratio ≤ 0.61），每步误差自行消除 |
| 前进行走 | 质心横向转移产生非对称地面接触冲击；step-to-step 误差不可对消 | 控制在稳定边界，swing 相阻尼勉强够；但每步残余 roll 误差无法清零，走 3–5 步后累积超出可恢复范围 |

**本质**：Kp=25 处于稳定边界，单步内误差不增长但也未快速收敛；原地踏步的对称性使误差天然抵消，掩盖了收敛速度不足的问题。前进行走打破了这种对称性，残余误差逐步累积，最终使机器人停止前进或倒向一侧。

#### 3.6.5 三因子联合机制（前进行走失稳路径）

```
高 Kp → ωn 超过稳定边界（3.28 Hz）
    ↓
Swing 相：控制力与 roll 误差同相，每周期注入能量（负阻尼）
    ↓
Touchdown 时：sole_roll 角度更大，冲击力矩更强
    ↓
冲击能量经传动弹性注入踝关节 roll 振荡（与自激共振）
    ↓
下一步以更大 roll 初始偏差出发 → 正反馈累积
    ↓
1–2 步后：joint_path/target_path 比值跃升（Kp40 Step6 = 4.36）
    ↓
目视可见剧烈踝关节 roll 抖动，机器人失去横向稳定性
```

#### 3.6.6 小结

数据完整支持该现象的机理解释：Kp=25 处于延迟条件下的稳定临界点（ωn ≈ 3.25 Hz ≈ π/(2τ)），在对称的原地踏步中尚可维持，但增益不足以支撑前进行走的步间误差收敛。Kp≥30 超出稳定边界，踝关节 roll 轴在摆动相产生负阻尼自激，叠加每步增大的落地冲击扰动，呈现可预测的逐步失稳路径——这与实测 Kp=40 在 step6 出现 4.36× 自激倍数、目视踝关节完全侧倒的现象完全吻合。

**改进方向**：降低 target 换向频率（加低通滤波至 < 5 Hz）比单纯调整 Kp 更有效，因为问题的物理根源在于"target 高频分量超出系统稳定带宽"而非 Kp 数值本身。

### 4.1 失效时序（修复后数据确认）

### 4.2 失效前兆与机制（修复后解读）

- **Step 3 swing**：右踝 pitch 目标幅值为 0（`tgt_range=0`），但关节仍运动 0.555 rad——这是脱离目标控制的自由振荡；
- **Step 4 swing**：pitch 过冲达 2.2×，说明伺服已进入不稳定工作区（增益过大或共振）；
- **Step 4 touchdown**：落地冲击后右踝 joint_range 同时降为 0，`aligned_track_err=0.261 rad`（目标仍有信号），符合**过流保护触发后关节锁死**的特征；
- Step 5–6 右踝 pitch/roll joint_range 均为 0，但 tracking_err 仍约 0.33–0.37 rad，确认为**执行器停止输出力矩而非目标信号消失**。

### 4.3 对整体步态的影响

右踝从 step 4 落地后锁死，左腿单独承担侧向稳定。step 5–6 左踝 pitch 目标幅值急增（step5 swing left pitch tgt_range=0.731 rad），控制器试图通过大幅目标补偿，但 joint_range 仅 0.352 rad（跟踪率 48%）。最终 step 6 左踝 swing aligned_track_err = 0.502 rad，机器人失去稳定落入跌倒序列。

**修复后核心发现（与旧版对比）**：

- 旧版："real 踝 roll 跟踪率 11–25%，sim 60–90%"——已修正。
- 修复后：**摆动相 real 踝 roll 跟踪率 77%，sim 仅 20%**。仿真在 ankle roll 方向的摆动相响应严重不足，是 sim 侧的主要建模缺失。
- **real 的核心问题转移到落地期**：ankle pitch 在 touchdown 窗口过冲 2.84×，knee pitch 过冲 2.40×，说明真机在落地冲击时关节产生了超出目标范围的被动运动（或反弹），而非不跟踪。

### 6.2 落地期过冲机制分析

touchdown 窗口（-50ms ~ +100ms）内 real 的 joint_range 远超 target_range：

- **ankle_pitch**：target 0.062 rad，joint 0.176 rad（比值 2.84）
- **knee_pitch**：target 0.115 rad，joint 0.277 rad（比值 2.40）

这种"落地期关节实际运动幅度远超目标幅度"的现象来源于：落地冲击产生的被动关节运动叠加在控制指令上，使得关节在 +50ms 之后出现被动回弹或冲击诱发的振荡，而控制器在该窗口内的调节已来不及抑制这一运动。

Sim 在 touchdown 期 ankle_pitch 比值仅 0.37，说明仿真的接触模型缺乏这种冲击反弹，关节被约束得过于刚性。

### 6.3 Support Leg 跟踪

支撑腿 hip_pitch 的 target range 高达 1.0–1.9 rad，但 joint range 仅 0.02–0.08 rad（real）/ 0.02–0.05 rad（sim），跟踪率均 < 10%。这是正常的——支撑相髋关节由地面约束和重力主导，而非主动跟随策略输出。

支撑腿 ankle_pitch（stance leg）：real joint_range/target_range 约 10–40%，sim 约 5–15%，real 略好，但两者都较低，说明支撑期踝关节主动调节能力有限，主要由地反力被动决定。

## 八、根因推断与改进建议（修复后版本）

### 8.1 根因分析

**根因一：真机落地期踝关节冲击反弹（最关键）**

touchdown 窗口内真机 ankle_pitch 运动幅度是目标的 2.84 倍，说明落地冲击产生了远超控制期望的被动踝关节运动。这直接导致：落地姿态不可控、地面接触力矩不规律、触地时刻的踝关节角度高度离散（std=0.10–0.16 rad）。仿真接触模型过刚性（比值仅 0.37），未建模真实的足端冲击柔性和关节被动运动特性。

**根因二：真机触地时踝关节背屈不足**

真机触地 ankle_pitch 均值 -0.07 至 -0.20 rad，仿真 -0.22 至 -0.24 rad，真机背屈约少 4–10°。踝关节背屈不足意味着落地时脚掌接触角度偏平甚至前掌先着地，冲击力沿腿部更直接传递，进一步放大冲击反弹。这既是控制策略的调节范围限制，也反映真机踝关节在摆动末期未能完全到达目标落地位置。

**根因三：仿真 ankle_roll 摆动相严重欠建模**

仿真 swing ankle_roll 跟踪比值仅 0.20，说明仿真关节在摆动期几乎不产生内外翻运动。策略在 sim 中学习到的 ankle_roll 控制模式在真机上无法复现（真机 0.77），两者行为模式根本不同。这表明 sim 的 ankle_roll 传动/惯性建模与真机差异显著，策略泛化到真机时行为已不一致。

**根因四：35/0.5 case 硬件级过载保护触发**

step 3 swing 右踝脱离目标自由振荡（tgt_range=0 但 jnt_range=0.555 rad），紧随 step 4 touchdown 后双轴同时锁死（joint_range=0，tracking_err≠0），符合电流过载保护触发特征。控制器缺乏单侧踝关节失效的降级处理能力，导致机器人继续以单侧代偿的方式运行直至跌倒。

**根因五：摆动相踝关节目标幅值偏大**

仿真输出的 ankle_pitch 目标幅值（0.16–0.21 rad）明显大于真机（0.09–0.17 rad），仿真中策略倾向于生成更大的踝关节摆动指令，但仿真关节无法完全跟随（gain=0.52）。策略在真机上落地时的目标轨迹可能因状态估计或 obs 差异导致与 sim 有偏差，是产生摆动末期欠伸展的间接原因。

**根因六：ankle_roll 轴自激振荡——弹性储能 + 负阻尼 + 冲击激励三因子联合**

ankle_roll vel_rms 分析揭示 real 存在 7 处 `jnt_vel > tgt_vel`（ratio > 1）的自激点，集中在 step3–6，sim 无任何自激点。自激不需要特殊条件，只需三个已存在的因子同时作用：① 真机与仿真 swing lag 相近（~76ms vs ~80ms），延迟相位亏欠导致控制环负阻尼（每周期向振荡注入能量）；② 真机踝关节存在传动弹性，前几步 target 拉偏关节后弹性势能积累，target 减小时势能以速度释放，形成 ratio > 1；③ 落地冲击向 roll 轴注入脉冲能量，与现有振荡同相时直接引燃自激。Sim 虽有相近延迟（①相同），但关节刚性建模（无②）+ 过刚性接触（无③）使微弱负阻尼被关节阻尼耗散，无法积累成自激。自激是 35/0.5 右踝锁死（过流保护）和 40/0.8 step6 右踝 11.6 rad/s 失控的直接动力学前驱。

**根因七：策略输出 target 本身的高频换向远超系统可达带宽**

实测 target 换向频率高达 22–37 Hz（对应振荡频率 11–18 Hz），而 76ms 延迟下系统稳定带宽上限仅 3.28 Hz，target 频率超出带宽 3–5 倍。关节无论增益如何调整，在物理上都无法跟踪如此高频的指令。真机 target 换向频率比 sim 高 30–33%（real 22.3/32.4 Hz vs sim 16.7/24.6 Hz），差异源于真机观测噪声更大，策略将噪声误判为状态偏差并持续输出高频修正——这是 sim2real gap 在策略输入端的传导路径。

### 8.2 改进建议

1. **引入传动弹性与阻尼建模（消除自激根因②）**：在 MuJoCo 中为 ankle_roll 关节添加弹性刚度 k 和粘滞阻尼 b（或 Dryden 摩擦模型），使 sim 关节在 roll 方向具有弹性回弹特性，让策略在训练中学习到弹性释放引发自激的场景，并学习主动抑制；

2. **接触模型加入法向柔性（消除自激根因③）**：在足端接触模型中引入法向弹簧阻尼（contact stiffness/damping），使冲击能量部分转化为关节振动而非直接被吸收，还原真机的冲击激励机制；

3. **target 低通滤波（抑制高频指令，优先级最高）**：在策略输出与电机指令之间加入截止频率 ≤ 5 Hz 的低通滤波器，将 target 换向频率从当前 22–37 Hz 压至系统稳定带宽（3.28 Hz）附近。这比调整 Kp/Kd 更直接有效，因为 Kp/Kd 不能改变"target 频率超过带宽"这一根本矛盾；

2. **观测噪声滤波**：对输入策略的 joint_pos 和 IMU 信号加滤波（截止频率与策略更新率 100Hz 匹配），抑制真机噪声放大策略输出频率的链路（当前 real target 比 sim 高 30%）；

3. **改进仿真 ankle_roll 建模**：在 MuJoCo 模型中引入踝关节 roll 方向的实际传动比（gear ratio）、弹性刚度和阻尼，使 sim 摆动相 ankle_roll 跟踪比值从 0.20 提升至接近真机 0.77 的水平；

4. **引入落地冲击柔性模型**：在足端接触模型中加入接触柔性（contact stiffness/damping），使 sim 落地期关节被动运动比值从 0.37 向真机 2.84 靠近，让策略在 sim 中学习冲击期的抑制控制；

5. **踝关节落地预位补偿**：在 touchdown 检测前 20ms 开始向目标角度（~-0.22 rad）做前馈平滑，弥补真机当前落地背屈不足的 4–10° 差距；

6. **故障检测与降级**：监测单侧踝关节 joint_range < 0.02 rad 且 tracking_err > 0.25 rad 持续 ≥ 2 步，触发减速 + 降低踝关节目标幅值的降级策略，防止 35/0.5 类型的硬件保护失效后无降级处理；

7. **落地期 target 平滑**：touchdown 检测后 50ms 窗口内对踝关节 pitch 目标施加速度限制或 hold，将落地期 target 换向频率从 23.7 Hz 压制下来，抑制关节过冲（当前 2.84×）；

8. **在线增益监控**：将 aligned_track_err_roll > 0.20 rad 作为在线步间监控指标，超标时提前介入，避免误差积累导致失稳。
