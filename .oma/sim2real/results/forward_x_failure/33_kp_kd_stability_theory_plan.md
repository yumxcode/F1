# 33 Kp/Kd 稳定性理论分析报告

## 结论摘要

`Kp35/Kd1.5` 比 `Kp35/Kd0.5`、`Kp40/Kd0.8` 更稳定，不是因为踝关节主频从 `3 Hz` 变成了别的频率，而是因为 `Kd` 提升同时改变了三个关键机制：

| 机制 | Kd 低时 | Kd1.5 后 | 稳定性意义 |
|---|---|---|---|
| 谐振峰值 | `zeta≈0.136`，`M_r≈3.7x` | `zeta≈0.408`，`M_r≈1.3x` | 3 Hz 附近扰动不再被强烈放大 |
| 衰减时间 | `tau≈386 ms` | `tau≈129 ms` | 残余振荡不再明显跨步累积 |
| 相位补偿 | PD 超前约 `15 deg` | PD 超前约 `39 deg` | 延迟导致的纠错时机错误被部分补偿 |

一句话：

```text
Kd=0.5 时，踝关节 3 Hz 附近像一个会共鸣的系统；
Kd=1.5 时，阻尼把共鸣峰和跨步残余都压下去，控制力矩的相位也更接近正确。
```

## 建模范围

把单个踝关节轴近似为二阶 PD 闭环系统：

```text
J_eff * qdd + Kd * qd + Kp * q = input/disturbance
```

其中：

| 符号 | 含义 |
|---|---|
| `q` | 关节跟踪误差，或围绕工作点的小扰动 |
| `J_eff` | 踝关节轴看到的等效转动惯量 |
| `Kp` | 关节刚度 |
| `Kd` | 关节阻尼 |
| `input/disturbance` | target 运动、触地冲击、延迟误差、传动误差等 |

该模型用于解释趋势，不是完整整机稳定性证明。真实系统还包含执行器动态、100 Hz action hold、1 kHz command loop、低通滤波、并联踝传动、接触切换、传感/通信延迟和机械偏置。

## 基础公式

标准二阶形式：

```text
qdd + 2*zeta*omega_n*qd + omega_n^2*q = input
```

与 PD 踝关节模型对应：

```text
omega_n = sqrt(Kp / J_eff)
f_n     = omega_n / (2*pi)
zeta    = Kd / (2*sqrt(Kp*J_eff))
```

若从 `Kp=35` 的实测 ankle residual 主模态约 `3 Hz` 反推：

```text
omega_n = 2*pi*3 = 18.85 rad/s
J_eff   = Kp / omega_n^2
        = 35 / 18.85^2
        ~= 0.0985 kg*m^2
```

本文沿用工作值：

```text
J_eff ~= 0.0965 kg*m^2
```

对应自然频率：

| Kp | `omega_n` rad/s | `f_n` Hz |
|---:|---:|---:|
| 25 | 16.10 | 2.56 |
| 30 | 17.63 | 2.81 |
| 35 | 19.04 | 3.03 |
| 40 | 20.36 | 3.24 |

这说明 `Kp=25~40` 本来就集中在 `2.5-3.2 Hz`。若 Welch PSD 使用 `2 s` 窗口，频率分辨率为：

```text
delta_f = 1 / T = 0.5 Hz
```

因此多个 Kp/Kd case 都显示 `3 Hz`，不代表真实频率完全相同，而是它们落在同一个低频模态带内。

## 机制一：谐振峰值被压低

### 物理直觉

踝关节可近似为弹簧-质量-阻尼系统：

```text
输入扰动 u(t) -> [J_eff] -> 关节响应 q(t)
                    |
                 Kp：回复刚度
                 Kd：耗散阻尼
```

当输入里含有接近自然频率的正弦成分时：

```text
u(t) = A*sin(omega*t)
```

输出稳态仍是同频正弦，但幅值会被系统放大或衰减：

```text
q(t) = A*|G(j*omega)|*sin(omega*t + phi)
```

令：

```text
r = omega / omega_n
```

标准二阶系统幅频响应为：

```text
|G(j*omega)| = 1 / sqrt((1-r^2)^2 + (2*zeta*r)^2)
```

直觉：

| 频率区域 | 响应 |
|---|---|
| 远低于自然频率 | 约 `1x`，基本跟随 |
| 接近自然频率 | 可能强烈放大 |
| 远高于自然频率 | 被衰减 |

### 谐振峰公式

对 `|G(j*omega)|` 求最大值，可得峰值位置：

```text
r_peak = sqrt(1 - 2*zeta^2)
```

该峰值只在：

```text
zeta < 1/sqrt(2) ~= 0.707
```

时存在。

把 `r_peak` 代回幅频公式，得到谐振峰值增益：

```text
M_r = 1 / (2*zeta*sqrt(1-zeta^2))
```

这表示系统对自然频率附近扰动的最大放大倍数。

### 数值对比

对 `Kp=35`、`J_eff=0.0965`：

```text
2*sqrt(Kp*J_eff) = 2*sqrt(35*0.0965) = 3.674
zeta = Kd / 3.674
```

| 配置 | `zeta` | `M_r` | 状态 |
|---|---:|---:|---|
| Kp35/Kd0.5 | 0.136 | 3.7x | 严重欠阻尼 |
| Kp40/Kd0.8 | 0.202 | 2.5x | 欠阻尼 |
| Kp35/Kd1.5 | 0.408 | 1.3x | 明显可控 |
| Kp35/Kd2.57 | 0.700 | 1.0x | 接近实用阻尼目标 |

`M_r` 随 `zeta` 非线性下降：

```text
M_r
5 |\
4 | \
3 |  \
2 |   \__
1 |      ----------------
  +------------------------ zeta
    0.1   0.3   0.5   0.7
```

所以 `Kd=0.5 -> 1.5` 的意义不是“振荡小一点”，而是把 `3 Hz` 附近的放大机制从 `3.7x` 压到 `1.3x`。

## 机制二：衰减时间短到无法跨步累积

### 从微分方程到衰减包络

看无外部输入时的自由响应：

```text
qdd + 2*zeta*omega_n*qd + omega_n^2*q = 0
```

特征根为：

```text
s = -zeta*omega_n +- j*omega_d
omega_d = omega_n*sqrt(1-zeta^2)
```

因此欠阻尼通解为：

```text
q(t) = A*exp(-zeta*omega_n*t)*cos(omega_d*t + phi)
```

其中：

```text
exp(-zeta*omega_n*t)  -> 衰减包络
cos(omega_d*t + phi)  -> 振荡项
```

所以衰减速度由特征根实部 `-zeta*omega_n` 决定。

### 时间常数

标准指数衰减：

```text
exp(-t/tau_decay)
```

与包络项对比：

```text
tau_decay = 1 / (zeta*omega_n)
```

展开：

```text
zeta    = Kd / (2*sqrt(Kp*J_eff))
omega_n = sqrt(Kp/J_eff)

zeta*omega_n = Kd / (2*J_eff)
```

因此：

```text
tau_decay = 2*J_eff / Kd
```

重要结论：

```text
Kp 主要控制振荡频率。
Kd 主要控制振荡衰减速度。
```

### 踝关节数值

取 `J_eff=0.0965`：

```text
tau_decay = 2*0.0965/Kd = 0.193/Kd 秒
```

| Kd | `tau_decay` | 含义 |
|---:|---:|---|
| 0.5 | 386 ms | 衰减到 37% 需要 386 ms |
| 1.5 | 129 ms | 衰减到 37% 需要 129 ms |
| 2.57 | 75 ms | 衰减到 37% 需要 75 ms |

若步态周期约 `692 ms`，半步态周期约 `346 ms`：

| Kd | 半步态 346 ms 后残余 | 整步态 692 ms 后残余 |
|---:|---:|---:|
| 0.5 | `exp(-346/386)=40.7%` | `exp(-692/386)=16.7%` |
| 1.5 | `exp(-346/129)=6.9%` | `exp(-692/129)=0.47%` |

直观图：

```text
残余幅值
100% |\
     |  \              Kd0.5, tau=386ms
 41% |    \------------ 半步态 346ms
 17% |       \--------- 整步态 692ms
     |
  7% |         \        Kd1.5, tau=129ms
  1% |             \---- 整步态 692ms
     +------------------------------------ t
       0     129ms    386ms        692ms
```

### 跨步积累解释

每次触地都会重新激励踝关节。如果上一周期残余还没衰减，下一次冲击会叠加。

低阻尼时：

```text
Kd0.5:
  第 1 步冲击 -> A
  半步后残余 -> 0.41A
  第 2 步冲击 -> 最坏约 1.41A
  半步后残余 -> 0.58A
  第 3 步冲击 -> 最坏约 1.58A
```

较高阻尼时：

```text
Kd1.5:
  第 1 步冲击 -> A
  半步后残余 -> 0.069A
  第 2 步冲击 -> 约 1.069A
```

这解释了现场现象：

```text
Kd0.5: 危险在于残余振荡能跨步保留并叠加。
Kd1.5: 每步结束前残余已经很小，难以跨步积累。
```

## 机制三：PD 相位超前部分抵消延迟滞后

### 延迟在频域里是什么

纯延迟：

```text
y(t) = u(t - tau)
```

拉普拉斯变换：

```text
G_delay(s) = exp(-s*tau)
```

令 `s=j*omega`：

```text
G_delay(j*omega) = exp(-j*omega*tau)
```

因此：

```text
|G_delay(j*omega)| = 1
angle(G_delay(j*omega)) = -omega*tau
```

纯延迟不改变幅值，但引入相位滞后。

若 `f=3 Hz`、`tau=112 ms`：

```text
omega = 2*pi*3 = 18.85 rad/s
phi_delay = -18.85*0.112 = -2.11 rad = -121 deg
```

`3 Hz` 周期为 `333 ms`，`112 ms` 正好约等于 `121/360` 个周期。

### PD 的相位超前

PD 控制器：

```text
C(s) = Kp + Kd*s
```

令 `s=j*omega`：

```text
C(j*omega) = Kp + j*Kd*omega
```

其相位为：

```text
phi_pd = atan(Kd*omega/Kp)
```

这是正相位，表示 D 项提前响应误差变化趋势。

对 `Kp=35`、`omega=18.85 rad/s`：

| Kd | `phi_pd` | 延迟 121 deg 扣除后剩余损失 | 距离 180 deg |
|---:|---:|---:|---:|
| 0.5 | 15 deg | 106 deg | 74 deg |
| 1.5 | 39 deg | 82 deg | 98 deg |
| 2.57 | 54 deg | 67 deg | 113 deg |

局部相位总账：

```text
延迟相位:  -121 deg
PD 超前:   +phi_pd
----------------------
剩余损失:  121 deg - phi_pd
```

### 为什么这只是局部解释

完整相位裕度还需要被控对象 `P(s)`、低通滤波、action hold、执行器动态、传动链路和传感延迟。这里不能证明整机稳定，只能说明：

```text
Kd 从 0.5 提到 1.5 时，
3 Hz 处 PD 相位超前从约 15 deg 增加到约 39 deg，
纠正力矩的时机更接近正确。
```

结合前两节：

```text
谐振峰压低       -> 能量放大减小
跨步残余降低     -> 振荡不易累积
相位损失减小     -> 纠错方向更准
--------------------------------
Kp35/Kd1.5 的综合响应明显改善
```

## 单个完整算例：Kp35/Kd1.5

给定：

```text
Kp = 35
Kd = 1.5
J_eff = 0.0965 kg*m^2
gait_period = 0.692 s
half_period = 0.346 s
delay_p75 = 0.112 s
```

计算：

```text
omega_n = sqrt(35/0.0965) = 19.04 rad/s
f_n = 19.04/(2*pi) = 3.03 Hz

zeta = 1.5/(2*sqrt(35*0.0965)) = 0.408
M_r = 1/(2*0.408*sqrt(1-0.408^2)) = 1.34x

tau_decay = 2*0.0965/1.5 = 0.129 s
半步残余 = exp(-0.346/0.129) = 6.9%
整步残余 = exp(-0.692/0.129) = 0.47%

3 Hz 下 PD 相位超前 = atan(1.5*19.04/35) = 39.2 deg
112 ms 延迟相位滞后 = 19.04*0.112 = 122.2 deg
局部剩余相位损失 ~= 83 deg
```

解释：

```text
3 Hz 模态仍存在，但放大峰值、跨步残余、相位滞后都显著改善。
系统从“持续欠阻尼振荡”跨入了“能在步态周期内衰减”的区域。
```

## 可解释与不可证明

可解释：

- 为什么提高 `Kd` 后，主频可能仍接近 `3 Hz`，但稳定性明显改善。
- 为什么 PSD peak power 比 peak frequency 更能反映振荡强度。
- 为什么 `Kp35/Kd1.5` 看起来跨过了稳定阈值。

不能单独证明：

- `J_eff` 精确等于 `0.0965 kg*m^2`。
- `Kd` 是稳定性的唯一因素。
- 实测 `3 Hz` 峰完全来自 PD 自然模态。
- `Kd` 越高一定越好。

## 验证计划

| 检查项 | 方法 | 预期 |
|---|---|---|
| `J_eff` 分 joint/side 估计 | `J_eff = Kp/(2*pi*f_peak)^2` | 左右差异过大说明机械/传动/零位影响强 |
| PSD peak power | `residual = joint_pos - pos_des_raw`，看 2.5-8 Hz 或 2.5-12 Hz | `Kd` 有效时 peak power 应下降 |
| 跨步残余 | 按 touchdown/swing 边界对齐 residual envelope | `Kd1.5` 残余应显著小于 `Kd0.5` |
| direction-change | `joint_dir_chg_hz` 作为折返/抖动指标 | 高值代表响应碎、chatter 风险高 |
| 延迟链路 | 比较 `pos_des_raw / pos_des_lpf / tau_des_lpf / actuator_cmd / actuator_state / joint_pos` | 用实测延迟更新 `phi_delay=omega*tau` |
| 静态偏置 | 比较 `mean(joint_pos)`、`mean(pos_des_raw)`、`mean(residual)` | 偏置需与振荡分开解释 |

## 推荐报告措辞

```text
Kp35/Kd1.5 之所以表现稳定，主要原因是 Kd 提升使踝关节闭环响应跨过了阻尼阈值。
基于实测约 3 Hz 的 ankle residual 模态反推 J_eff ~= 0.0965 kg*m^2 后，Kd0.5 对应 zeta ~= 0.136、M_r ~= 3.7x、衰减时间常数约 386 ms；Kd1.5 对应 zeta ~= 0.408、M_r ~= 1.3x、衰减时间常数约 129 ms。
在约 692 ms 的步态周期下，Kd0.5 会留下显著跨步残余振荡，而 Kd1.5 能在下一次同类事件前耗散大部分残余。
同时，Kd1.5 在 3 Hz 附近提供约 39 deg 的 PD 相位超前，比 Kd0.5 的约 15 deg 更能抵消延迟带来的相位滞后。
因此，主频仍可能接近 3 Hz，但 PSD power、残余包络和纠错相位都应明显改善。
```
