### 2.2 失稳特征分析

**与左踝 Pitch 失稳的对比**：

| 特征 | 左 Pitch 失稳 | 左 Roll 失稳 |
|---|---|---|
| 失稳触发 | 第 3 轮 | 第 3 轮 |
| **主轴失稳** | ✅ 主轴暴走 184 mrad | 主轴 −14 mrad（中等） |
| **耦合轴失稳** | 耦合 40 mrad | ✅ **耦合暴走 183 mrad** |
| 主要崩溃方向 | Pitch（前倾） | **Pitch（前倾，通过耦合）** |
| 主轴峰速 | 0.49 rad/s | 2.72 rad/s |
| **耦合峰速** | 0.41 rad/s | **5.07 rad/s** |
| **耦合峰力矩** | 1.38 Nm | **10.78 Nm** |

**关键发现**：Roll 测试的失稳并非 Roll 方向自身失控，而是 **Pitch 方向（耦合轴）崩溃**。
- 耦合 Pitch 运动 183 mrad = 10.5° → 机器人前倾倒地
- 耦合峰值力矩 10.78 Nm → 远超踝关节正常范围
- **根因相同**：无论激励哪个轴，Pitch 方向的重力不稳定性都是致命的

### 3.3 共性结论

所有失稳均因 **Pitch 方向前倾**：
- 零位站立时，身体重心偏前
- 重力在 Pitch 方向产生持续前倾力矩
- KP=35 踝关节无法抵抗该力矩
- 即使激励 Roll 轴，Pitch 方向也会通过耦合崩溃

## 4. 结论与建议

### 4.1 核心结论

1. **4 组地面测试中 2 组失稳倒地，1 组接近失稳**
2. **所有失稳方向均为 Pitch 前倾**，即使 Roll 测试也不例外
3. **KP=35 完全不适合地面站立场景**
4. **右侧比左侧略稳**，但差距很小（初始条件敏感）

### 4.2 改进方案优先级

| 优先级 | 方案 | 操作 | 预期效果 |
|---|---|---|---|
| **P0** | **重力补偿前馈** | 在 effort 字段加入估算的重力力矩 | 卸载 Pitch 方向负载，恢复正常跟踪 |
| P0 | 大幅提高 Pitch KP | 踝关节 Pitch KP ≥ 200 | 可抵抗前倾力矩 |
| P1 | 使用 stand 姿态 | `startup_pose_mode: stand` | 弯膝减小 Pitch 力臂 |
| P1 | 减少重复次数 | `repeat_count: 1` | 避免累积漂移 |
| P2 | 增加安全停止 | 偏离基线 >50 mrad 时紧急停止 | 保护实物 |
