## 5. 结论与紧急建议

### 5.1 核心结论

1. **KP=35 在地面 Pitch 轴不仅无法跟踪，而且会导致机器人倒地**
2. **零位站立 + 低踝关节增益 = 不稳定系统**：重力力矩持续累积，最终超过静摩擦极限
3. **左右不完全对称**：左侧漂移更快（可能是模型细微不对称或初始条件差异）
4. **3 轮重复测试时间过长**：在不稳定系统上，18 秒测试会积累致命漂移

### 5.2 紧急措施

| 优先级 | 措施 | 说明 |
|---|---|---|
| **P0** | **减少到 1 轮测试** (`repeat_count: 1`) | 避免累积漂移导致倒地 |
| **P0** | **大幅提高 Pitch KP** (≥200) | 让踝关节有能力抵抗重力力矩 |
| **P1** | 增加重力补偿前馈 | 根本解决方案 |
| **P1** | 使用 `startup_pose_mode: stand` | 弯膝减小重力力臂 |
| **P2** | 增加安全检测（位移超限自动停止） | 防止实物测试损坏 |

### 5.3 安全阈值建议

```yaml
# 建议增加的安全参数：
max_primary_deviation_rad: 0.05   # 主轴偏离基线超过 50 mrad 立即停止
max_body_tilt_rad: 0.1            # 身体倾角超过 5.7° 立即停止
```

> ⚠️ **实物测试前必须解决此问题，否则机器人会倒地并可能损坏。**
