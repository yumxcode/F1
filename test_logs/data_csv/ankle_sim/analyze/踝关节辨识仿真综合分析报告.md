## 3. KP 增益效果分析

### 3.1 KP 30→35 改善量

| 指标 | Roll 平均改善 | Pitch 平均改善 |
|---|---|---|
| **上升时间** | −16.0 ms (−14.6%) | −16.0 ms (−14.8%) |
| **稳定时间** | −35.0 ms (−16.2%) | −33.5 ms (−16.3%) |
| **跟踪比** | +0.77% | +0.77% |
| **稳态误差** | −0.049 mrad (−14.4%) | −0.051 mrad (−15.1%) |

**关键发现**：
- KP 每增加 5，上升时间稳定减少约 **16 ms**
- 改善比例在 Roll 和 Pitch 之间高度一致（~14.7%）
- 稳态误差按相同比例改善
- 无超调的安全裕度充足

### 3.2 线性外推模型

基于 8 组数据拟合：

```
rise_time(ms) ≈ 109 − 3.2 × (KP − 30)
```

| KP | 预测上升时间 | 距目标 84ms | 状态 |
|---|---|---|---|
| 30 | 109 ms | +25 ms | ❌ |
| 35 | 93 ms | +9 ms | ⚠️ |
| **38** | **~83 ms** | **≈ 达标** | ✅ |
| 40 | ~77 ms | −7 ms | ✅ |
| 45 | ~61 ms | −23 ms | ✅ |
| 50 | ~45 ms | −39 ms | ⚠️ 可能超调 |

| Pitch KP=35: 左 vs 右 | 0.0 ms | 0.00% | ✅ 完全对称 |

**结论：左右踝在仿真中完全对称，同一参数组可直接用于两侧，无需分别调参。**

### 4.2 Roll vs Pitch 轴间对比

**结论：Pitch 轴始终比 Roll 快约 1.5ms，差异极小，可使用统一 KP。**

## 5. 耦合分析

### 5.1 耦合量汇总

| 激励轴 | 耦合速度 | 耦合力矩 | 随 KP 变化 |
|---|---|---|---|
| **Roll→Pitch** | 0.005 rad/s | 0.004 Nm | 不变 |
| **Pitch→Roll** | 0.067~0.068 rad/s | 0.035~0.036 Nm | 不变 |

### 5.2 耦合特征

- **Pitch→Roll 耦合远大于 Roll→Pitch**（速度比 13:1，力矩比 9:1）
- 耦合量**不随 KP 增大而变化**，说明耦合来源于**机械结构**而非控制增益
- 位移耦合极小（< 0.02 mrad），**不影响跟踪精度**
- 左右侧耦合量完全一致，进一步验证结构对称性

### 5.3 耦合风险评估

| 风险 | 评估 |
|---|---|
| 位移串扰 | ✅ 可忽略 (<0.1% 阶跃幅值) |
| 速度串扰 | ⚠️ Pitch→Roll 为主关节的 21%，行走时需关注 |
| 高 KP 下恶化 | ✅ 不会，耦合来源于结构 |

## 7. 结论

### 7.1 核心发现

1. **系统特性明确**：全部过阻尼、零超调、零振荡，控制品质优良
2. **KP 线性可控**：上升时间与 KP 呈线性关系，每 +5 KP 减少 ~16ms
3. **完美对称**：左右差异 < 1ms，轴间差异 < 2ms
4. **耦合可控**：Pitch→Roll 结构耦合稳定，不随增益变化
5. **重复性极佳**：同条件 3 次标准差 < 0.1%

### 7.2 最优参数推荐

| 参数 | 推荐值 | 依据 |
|---|---|---|
| **KP** | **40** | 外推上升时间 ~77ms < 84ms 目标，留有 8% 裕度 |
| **KD** | **0.5** | 当前 KP=35 零超调，KP=40 仍有安全裕度 |
| **左右统一** | ✅ | 对称性已验证 |
| **Pitch/Roll 统一** | ✅ | 轴间差异 < 2ms |

### 7.3 后续实验计划
