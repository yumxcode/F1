## 4. 失稳机理分析

### 4.1 重力负载模型

```
                    空中测试                         地面测试
                 ┌────────────┐                 ┌────────────┐
  目标 Δθ       │  τ = KP·Δθ │ → Δθ_actual     │  τ = KP·Δθ │
  0.015 rad     │  = 0.525Nm │   ≈ 14 mrad     │  = 0.525Nm │ → Δθ_actual ≈ 0.75 mrad
                 └────────────┘                 │  − τ_gravity│   (Roll)
                    无外力                       └────────────┘   或反向 (Pitch)
                                                  τ_gravity >> τ_control
```

### 4.2 各轴重力力矩估算

| 轴 | 估算重力力矩 | KP=35 控制力矩 | 控制/负载比 | 后果 |
|---|---|---|---|---|
| **Pitch** | **~2.5 Nm** | 0.525 Nm | **21%** | 反向响应+失稳 |
| **Roll** | **~0.5 Nm** | 0.525 Nm | **105%** | 极弱跟踪(5%) |

- Pitch 方向：身体重心在脚掌前方 → 持续前倾力矩 ~2.5 Nm → 控制力矩仅够 21%
- Roll 方向：零位时重心大致在侧向中线 → 力矩较小 → 勉强能产生正向响应

### 4.3 失稳链条

```
零位站立
  → Pitch方向重力持续压迫 (−2.5 Nm)
    → KP=35 无法抵抗 → 基线每轮下降 8-9 mrad
      → 累积到 ~55 mrad 后身体前倾角增大
        → 重力力臂增大（正反馈）
          → 超过地面摩擦锥极限
            → 🔴 机器人前倾倒地

即使激励 Roll 轴，Pitch 方向也会通过基线漂移累积 → 最终倒地
```

## 6. 耦合分析（地面 vs 空中）

### 6.1 耦合量对比

| 激励轴 | 耦合指标 | 空中 | 地面 | 变化 |
|---|---|---|---|---|
| Roll→Pitch | 耦合位移 | 0.005 mrad | −4.7~−9.3 mrad | **↑ 940~1860x** |
| Roll→Pitch | 耦合力矩 | 0.035 Nm | 1.78 Nm | **↑ 51x** |
| Pitch→Roll | 耦合位移 | 0.067 mrad | −0.16 mrad | ↑ 2.4x |
| Pitch→Roll | 耦合力矩 | 0.036 Nm | 0.04 Nm | ≈ 不变 |

### 6.2 耦合机理变化

- **空中**：耦合来源于**机械结构**（串联运动链），幅值小且恒定
- **地面**：耦合来源于**地面反力重分配** + 机械结构
  - Roll 激励 → 重心侧移 → 前后方向地面反力矩变化 → Pitch 被动运动
  - Pitch 激励 → 前倾/后仰 → 侧向影响极小（因为站立对称）
- **Roll→Pitch 耦合暴增**是地面反力的直接后果

## 8. 结论与建议

### 8.1 核心结论

1. **KP=35 在地面完全不可用**：全部欠跟踪，2/4 组失稳倒地
2. **Pitch 轴是关键瓶颈**：前倾重力力矩 ~2.5 Nm 远超控制力矩 0.525 Nm
3. **空中标定结果不可直接迁移到地面**：跟踪比从 95% 降至 5%/负值
4. **累积漂移导致失稳**：基线每轮漂移 1~9 mrad，3 轮后可触发倒地
5. **地面耦合**：Roll→Pitch 耦合暴增（地面反力），即使 Roll 测试也可因 Pitch 倒地

### 8.2 改进方案

| 方案 | 操作 | Pitch 预期 | Roll 预期 | 风险 |
|---|---|---|---|---|
| **A. 重力补偿前馈** | `effort = τ_gravity` | ✅ 恢复正常跟踪 | ✅ 改善跟踪 | 需准确估算力矩 |
| **B. 大幅提高 KP** | Pitch KP≥200, Roll KP≥100 | ⚠️ 可能跟踪 | ✅ 可能跟踪 | 接近电机极限 |
| C. stand 姿态 | `startup_pose_mode: stand` | ⚠️ 缓解 | ⚠️ 缓解 | 不解决根本问题 |
| D. 减少重复次数 | `repeat_count: 1` | 避免累积倒地 | 避免累积倒地 | 仅治标 |
| E. 安全检测 | 偏离>50mrad停止 | 保护硬件 | 保护硬件 | 不改善跟踪 |

### 8.3 推荐策略

**短期（快速验证）**：
```yaml
# 方案 B: 大幅提高增益
test_kp: 200        # Pitch 轴
# 或
test_kp: 100        # Roll 轴
repeat_count: 1     # 减少到 1 轮避免倒地
```

**中期（根本解决）**：
```
方案 A: 在 StepControl 中增加重力补偿前馈
  effort = estimated_gravity_torque
  position = baseline + step_amplitude
  KP = 35 (原值即可)
  KD = 0.5

这样 KP 只负责跟踪偏差，effort 前馈抵消重力负载。
```
