# 踝关节辨识实验报告：右踝 Roll 轴阶跃响应

## 1. 实验概述

| 项目 | 内容 |
|---|---|
| **测试关节** | 右踝 Roll (`right_ankle_roll_joint`) |
| **耦合关节** | 右踝 Pitch (`right_ankle_pitch_joint`) |
| **测试模式** | 阶跃 (step) |
| **运行环境** | MuJoCo 仿真 |
| **数据文件** | `right_roll_step_kp35_kd0.5.csv` |

## 2. 实验参数

### 2.1 控制参数

| 参数 | 值 | 说明 |
|---|---|---|
| test_kp | **35** | 测试关节位置刚度 |
| test_kd | 0.5 | 测试关节阻尼 |
| hold_kp | 30.0 | 保持关节刚度 |
| hold_kd | 1.0 | 保持关节阻尼 |

### 2.2 测试流程

| 参数 | 值 |
|---|---|
| 阶跃幅值 | 0.015 rad |
| 预保持/激励/后保持 | 3.0 / 1.0 / 2.0 s |
| 重复次数 | 3 次 |
| 总采样数 | 18000 点 |

## 3. 实验结果

### 3.1 关键指标汇总（3 次均值）

| 指标 | 均值 | 评价 |
|---|---|---|
| **跟踪比** | 95.39% | 良好 |
| **上升时间** | 93.7 ms | ⚠️ 超标 (>84ms) |
| **稳定时间** | 183.0 ms | 偏慢 |
| **峰值时间** | 415.7 ms | ❌ 不可用 |
| **稳态误差** | 0.286 mrad | 极小 |
| **超调** | 0 | 无 |
| **耦合峰值速度** | 0.005 rad/s | 极小 |
| **响应类型** | well_damped_tracking | 过阻尼 |

### 3.2 与右踝 Roll KP=30 对比

| 指标 | KP=30 | KP=35 | 变化 |
|---|---|---|---|
| **跟踪比** | 94.62% | 95.39% | +0.77% ↑ |
| **上升时间** | 110.1 ms | 93.7 ms | **−14.9%** ↓ |
| **稳定时间** | 219.0 ms | 183.0 ms | **−16.4%** ↓ |
| **稳态误差** | 0.334 mrad | 0.286 mrad | −14.4% ↓ |
| **峰值速度** | 0.356 rad/s | 0.403 rad/s | +13.2% ↑ |

### 3.3 左右 Roll 对称性对比（KP=35）

| 指标 | 左踝 Roll | 右踝 Roll | 差异 |
|---|---|---|---|
| **跟踪比** | 95.47% | 95.39% | −0.08% |
| **上升时间** | 93.8 ms | 93.7 ms | −0.1 ms |
| **稳定时间** | 180.0 ms | 183.0 ms | +3 ms |
| **稳态误差** | 0.297 mrad | 0.286 mrad | −0.011 mrad |
| **峰值速度** | 0.402 rad/s | 0.403 rad/s | ≈0 |
| **耦合速度** | 0.005 rad/s | 0.005 rad/s | ≈0 |

**结论：左右 Roll 在 KP=35 下高度对称，参数可统一使用。**
