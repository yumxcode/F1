# 踝关节辨识实验报告：右踝 Roll 轴阶跃响应

## 1. 实验概述

| 项目 | 内容 |
|---|---|
| **测试关节** | 右踝 Roll (`right_ankle_roll_joint`) |
| **耦合关节** | 右踝 Pitch (`right_ankle_pitch_joint`) |
| **测试模式** | 阶跃 (step) |
| **运行环境** | MuJoCo 仿真 |
| **数据文件** | `right_roll_step_kp30_kd0.5.csv` |

## 2. 实验参数

### 2.1 控制参数

| 参数 | 值 | 说明 |
|---|---|---|
| test_kp | 30 | 测试关节位置刚度 |
| test_kd | 0.5 | 测试关节阻尼 |
| hold_kp | 30.0 | 保持关节刚度 |
| hold_kd | 1.0 | 保持关节阻尼 |

### 2.2 测试流程

| 参数 | 值 |
|---|---|
| 阶跃幅值 | 0.015 rad |
| 预保持/激励/后保持 | 3.0 / 1.0 / 2.0 s |
| 重复次数 | 3 次 |
| 总采样数 | 18000 点 |

## 3. 实验结果

### 3.1 关键指标汇总（3 次均值）

| 指标 | 均值 | 评价 |
|---|---|---|
| **跟踪比** | 94.62% | 良好 |
| **上升时间** | 110.1 ms | ⚠️ 超标 (>84ms) |
| **稳定时间** | 219.0 ms | 偏慢 |
| **峰值时间** | 459.0 ms | ❌ 不可用 |
| **稳态误差** | 0.334 mrad | 极小 |
| **超调** | 0 | 无 |
| **耦合峰值速度** | 0.005 rad/s | 极小 |
| **响应类型** | well_damped_tracking | 过阻尼 |

### 3.2 左右 Roll 对称性对比（KP=30）

| 指标 | 左踝 Roll | 右踝 Roll | 差异 |
|---|---|---|---|
| **跟踪比** | 94.71% | 94.62% | −0.09% |
| **上升时间** | 109.4 ms | 110.1 ms | +0.7 ms |
| **稳定时间** | 214.0 ms | 219.0 ms | +5 ms |
| **稳态误差** | 0.347 mrad | 0.334 mrad | −0.013 mrad |
| **耦合速度** | 0.005 rad/s | 0.005 rad/s | ≈0 |

**结论：左右 Roll 在 KP=30 下高度对称，差异可忽略。**
