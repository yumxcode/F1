# 踝关节辨识实验报告：右踝 Pitch 轴阶跃响应

## 1. 实验概述

| 项目 | 内容 |
|---|---|
| **测试关节** | 右踝 Pitch (`right_ankle_pitch_joint`) |
| **耦合关节** | 右踝 Roll (`right_ankle_roll_joint`) |
| **测试模式** | 阶跃 (step) |
| **运行环境** | MuJoCo 仿真 |
| **数据文件** | `right_pitch_step_kp30_kd0.5.csv` |

## 2. 实验参数

### 2.1 控制参数

| 参数 | 值 | 说明 |
|---|---|---|
| test_kp | 30 | 测试关节位置刚度 |
| test_kd | 0.5 | 测试关节阻尼 |
| hold_kp | 30.0 | 保持关节刚度 |
| hold_kd | 1.0 | 保持关节阻尼 |

### 2.2 测试流程

| 参数 | 值 |
|---|---|
| 阶跃幅值 | 0.015 rad |
| 预保持/激励/后保持 | 3.0 / 1.0 / 2.0 s |
| 重复次数 | 3 次 |
| 总采样数 | 18000 点 |

## 3. 实验结果

### 3.1 关键指标汇总（3 次均值）

| 指标 | 均值 | 评价 |
|---|---|---|
| **跟踪比** | 94.66% | 良好 |
| **上升时间** | 108.3 ms | ⚠️ 超标 (>84ms) |
| **稳定时间** | 198.0 ms | 偏慢 |
| **峰值时间** | 522.0 ms | ❌ 不可用 |
| **稳态误差** | 0.382 mrad | 极小 |
| **超调** | 0 | 无 |
| **耦合峰值速度** | 0.068 rad/s | 有一定耦合 |
| **耦合峰值力矩** | 0.036 Nm | 有一定耦合 |
| **响应类型** | well_damped_tracking | 过阻尼 |

### 3.2 左右 Pitch 对称性对比（KP=30）

| 指标 | 左踝 Pitch | 右踝 Pitch | 差异 |
|---|---|---|---|
| **跟踪比** | 94.66% | 94.66% | ≈0 |
| **上升时间** | 108.3 ms | 108.3 ms | ≈0 |
| **稳定时间** | 212.0 ms | 198.0 ms | 右踝快 14ms |
| **稳态误差** | 0.323 mrad | 0.382 mrad | 右踝稍大 |
| **耦合速度** | 0.067 rad/s | 0.068 rad/s | ≈0 |
| **耦合力矩** | 0.035 Nm | 0.036 Nm | ≈0 |

**结论：左右 Pitch 在 KP=30 下对称性优秀，跟踪比和上升时间完全一致。**

### 3.3 右踝 Pitch vs 右踝 Roll（KP=30）

| 指标 | Pitch | Roll | 说明 |
|---|---|---|---|
| **上升时间** | 108.3 ms | 110.1 ms | Pitch 略快 |
| **稳定时间** | 198.0 ms | 219.0 ms | Pitch 明显快 |
| **耦合速度** | **0.068 rad/s** | 0.005 rad/s | Pitch→Roll 耦合大 13 倍 |
